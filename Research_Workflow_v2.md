# Research Workflow v2 - Autonomous Research Laboratory

## Complete Workflow

1. Phase 1: Discovery - Detect anomalies, strategy degradation
2. Phase 2: Patterns - Extract success/failure patterns
3. Phase 3: Factory - Generate strategy candidates from patterns
4. Phase 4: Batch - Create and execute experiment batches
5. Phase 5: Benchmark - Multi-dimensional scoring + cross-validation
6. Phase 6: Continuous Loop - Automated research cycles with weekly summaries
7. Phase 7: Director - Mission planning, portfolio management, roadmap
8. Phase 8: Dashboard - Structured data for visualization

## Key Principles
- Pure engine computation
- No database access from engine
- Reproducible experiments
- Human-in-the-loop review
