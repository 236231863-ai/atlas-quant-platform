# Atlas User Persona — v3.7.0

> 三档目标用户画像。每个画像包含：背景 / 动机 / 痛点 / 高频行为 / 成功标准。

---

## 用户 1：彩票数据研究用户（核心）

**化名**：老周，45 岁，个体户，买大乐透 10 年。

| 维度 | 描述 |
|------|------|
| 背景 | 每周买 2-3 期大乐透，习惯研究走势图 |
| 动机 | 想知道"哪些号最近热""这期和历史哪期像" |
| 痛点 | 纸面走势图费眼；网上信息零散不可信；怕被"必中"话术骗 |
| 高频行为 | 每天看数据看板 → 周末跑回测 → 偶尔导出报告 |
| 成功标准 | 5 分钟内看到今日数据变化 + 一份可信的号码统计 |

**核心需求**：**真实数据 + 诚实统计**。他能接受"彩票是随机的"，但不能接受"拿 15 期数据忽悠人"。

## 用户 2：数据分析学习用户

**化名**：小美，23 岁，研究生，正在学数据分析。

| 维度 | 描述 |
|------|------|
| 背景 | 学 pandas/matplotlib，缺一个有意思的真实数据集练手 |
| 动机 | 用真实数据练习统计、可视化、回测概念 |
| 痛点 | 课程数据集无聊；真实项目不知道从哪下手 |
| 高频行为 | 看图表 → 研究"回测是什么意思" → 导出图表做作业 |
| 成功标准 | 理解样本内外、随机基准这些概念，能导出图写报告 |

**核心需求**：**教学价值**。把"回测""样本外"这种概念做直观、可导出。

---

## 用户 3：专业研究用户

**化名**：陈老师，38 岁，统计系讲师，对彩票随机性建模有兴趣。

| 维度 | 描述 |
|------|------|
| 背景 | 会写代码，用 R/Python，关注随机过程 |
| 动机 | 用真实开奖数据验证"号码是否独立随机"这个命题 |
| 痛点 | 找 1000+ 期干净数据难；现有工具不可信 |
| 高频行为 | 深挖数据质量 → 跑自定义回测 → 导出 CSV 做外部统计 |
| 成功标准 | 1000+ 期数据可导出，回测方法学上站得住 |

**核心需求**：**数据完整 + 方法诚实**。他会检查你的可信等级、样本划分是否严谨。

---

## 三档用户优先级

| 优先级 | 用户 | 原因 |
|--------|------|------|
| P0 | 彩票数据研究用户 | 最广、最付费意愿强、最需要"真实+诚实" |
| P1 | 数据分析学习用户 | 口碑传播者，为未来社区打基础 |
| P2 | 专业研究用户 | 数量少但背书价值高，验证方法学 |

## 用户需求模型总结

**所有用户的共同底线**：数据必须真实（≥500 期）、方法必须诚实（不骗中奖率）。
**分层需求**：
- 研究用户要"省心"（每天自动看变化）
- 学习用户要"懂"（概念直观可导出）
- 专业用户要"严"（数据全、方法严谨）
