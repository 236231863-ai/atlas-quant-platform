# Atlas v4.7 产品策略（Product Strategy）

版本：v4.7 · 个人彩票行为分析助手 · 2026-08-05

## 产品定位

**帮助用户看懂自己的购彩行为，而不是预测彩票。**

## 核心红线

- ❌ 禁止中奖预测 / 号码预测 / 提高中奖概率功能
- 系统必须明确：**彩票开奖结果具有随机性，任何号码组合理论中奖概率相同**

## 5 个核心场景

| # | 用户问题 | 对应模块 |
|---|---------|---------|
| 1 | 我最近一年买彩票花了多少钱？ | behavior_analysis（总投入） |
| 2 | 我的中奖率怎么样？ | behavior_analysis（中奖次数/ROI） |
| 3 | 我的投注方式是否重复？ | strategy_review（重复比例） |
| 4 | 我的购彩风险等级是多少？ | BehaviorScore（健康分） |
| 5 | 我过去的方法有没有效果？ | asset_center（年度 ROI/回撤） |

## Phase 规划

| Phase | 内容 |
|-------|------|
| P0 | 产品冻结 |
| P1 | 用户投注历史分析引擎（engine/behavior_analysis，10 指标） |
| P2 | 投注健康评分（BehaviorScore，非中奖评分） |
| P3 | 资产报告 2.0（年度 ROI/最大回撤/中奖分布） |
| P4 | 策略复盘系统（strategy_review，历史行为总结） |
| P5 | AI 助手融合（行为/资产/健康分） |
| P6 | 用户留存（每周彩票报告 + 月度复盘提醒） |
| P7 | Red Team |

## 用户价值

通过真实历史投注数据，分析**用户自己**的购彩行为、资金风险、中奖反馈、长期收益——诚实、不诱导、不预测。

每 Phase 必须输出：Product Review + 用户价值验证 + 测试报告 + 桌面入口 + 真实场景验证。
