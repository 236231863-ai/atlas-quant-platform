# Atlas v4.7 Phase 1 Product Review：用户投注历史分析引擎

> 2026-08-05

## 产品目标

读取真实历史票据，生成用户投注画像（10 指标），回答「花了多少钱/中奖率/风险」。

## 交付

| 模块 | 功能 |
|------|------|
| `engine/behavior_analysis/analysis.py` | BehaviorAnalyzer：总投入/中奖/净收益/ROI/平均每期/中奖次数/等级分布/最大亏损/连续未中/频率 |
| `engine/behavior_analysis/__init__.py` | 导出 |

## 10 指标（真实数据驱动）

总投入 / 总中奖 / 净收益 / ROI / 平均每期投入 / 中奖次数 / 中奖等级分布 / 最大亏损周期 / 连续未中奖 / 投注频率

## 用户价值

「我最近一年花了多少」「我的中奖率」——用真实历史数据回答，诚实展示负期望。
