# Atlas v4.7 Phase 6 Product Review：用户留存设计

> 2026-08-05

## 产品目标

每周彩票报告（购买/中奖/投入/风险提醒）+ 月度复盘提醒 → 用户每周回来。

## 交付

| 模块 | 功能 |
|------|------|
| `engine/behavior_analysis/weekly.py` | WeeklyReportBuilder：本周购买/中奖/投入/净收益/风险提醒 |

## 示例

```
📅 本周彩票报告（2026-08-03 ~ 2026-08-09）
· 购买：5 次 · 投入 ¥10
· 中奖：1 次 · ¥7 · 净收益 ¥-3
· ⚠️ 本周未中奖，注意控制投入
```

## 用户价值

每周固定节奏的「彩票行为回顾」——留存钩子 + 风险提醒。
