# Atlas v4.7 Phase 2 Product Review：投注健康评分

> 2026-08-05

## 产品目标

BehaviorScore：非中奖评分，四维度（资金管理40/投注纪律30/复盘习惯20/风险意识10）。

## 交付

| 模块 | 功能 |
|------|------|
| `engine/behavior_analysis/score.py` | BehaviorScoreBuilder：四维度 + 总分 + 等级 + 优势/风险 |

## 示例

```
🩺 购彩健康分
· 总分：72/100（良好）
  资金管理：28/40 · 投注纪律：22/30 · 复盘习惯：14/20 · 风险意识：8/10
· 优势：每期投入稳定且克制
· 风险：购买频率过高
```

## 用户价值

回答「我的购彩风险等级」，用行为管理维度评分（非中奖能力），诚实不诱导。
