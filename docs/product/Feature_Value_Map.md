# Atlas Feature Value Map — v3.8.0

## 1. 功能价值矩阵

| 功能 | 用户价值 | 使用频次 | 商业价值 | 优先级 |
|------|----------|----------|----------|--------|
| 数据看板 | 高（一眼看数据）| 高 | 中（免费拉新）| P0 |
| 数据分析图表 | 高（可视化）| 中 | 中 | P0 |
| 回测中心 | 高（核心差异化）| 中 | 高（PRO 锚点）| P0 |
| 研究报告 | 中（成果）| 低 | 高（导出=PRO）| P1 |
| AI 助手 | 中（问答）| 低 | 高（AI=PRO）| P1 |
| 每日智能 | 中（留存）| 高 | 高（PRO）| P1 |
| 帮助中心 | 低（支持）| 低 | 低 | P2 |

## 2. 价值归因（v3.8.0 product_value）
每个功能按 usage/duration/satisfaction/conversion 四维打分，识别：
- 高价值功能（投资）
- 低价值功能（优化或砍）

## 3. 免费 vs 付费功能
- FREE：数据看板、基础分析、基础回测、基础导出。
- PRO：高级分析、深度回测、全格式导出、每日智能。
- ENTERPRISE：AI 助手、优先支持、批量分析。

## 4. 北极星
**"每周完成 ≥1 次有效分析的用户比例"** 作为产品健康度核心指标。
