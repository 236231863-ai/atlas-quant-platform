# Atlas v4.0.0 个人决策智能层 — 产品设计

> 版本：v4.0.0
> 日期：2026-08-03
> 状态：已冻结（Phase 0）

---

## 1. 产品定位

Atlas 从「彩票量化分析工具」升级为「**个人智能决策助手**」。

**核心闭环**：
```
用户行为 → 数据积累 → 风险分析 → 行为洞察 → 方案优化 → 持续学习
```

**重要声明**：这不是彩票预测。而是帮助用户了解自己的投注行为，并进行风险管理。

## 2. 产品边界（红线）

### ✅ 提供
- 行为分析（投注频率/投入趋势/追号习惯）
- 资金管理（预算规划/超额提醒）
- 历史复盘（投入收益/中奖累计）
- 风险洞察（行为风险等级）
- 持续改进（建议与趋势追踪）

### ❌ 禁止
- 预测中奖号码
- 提高中奖概率
- 稳赚
- 任何暗示能改变中奖可能性的表达

## 3. 用户问题（产品要解决的真实问题）

| # | 用户问题 | 系统响应 | 入口 |
|---|---------|---------|------|
| 1 | 我过去买了多少钱？ | 投入统计（月/年投入）| 个人中心/行为分析 |
| 2 | 我的投注习惯有没有问题？ | 行为风险等级 + 建议 | 个人中心/行为分析 |
| 3 | 我的资金风险是多少？ | 预算占比/超额提醒 | 工作台/资金管理 |
| 4 | 我的号码组合是否重复？ | 重复率/集中风险 | 量化中心/组合分析 |
| 5 | 历史行为是否改善？ | 趋势对比/改进评估 | 个人中心/趋势 |

## 4. 用户价值场景

### 场景 1：了解投入
```
用户：「我最近买彩票情况怎么样？」
系统：你最近共投注 45 期，月均投入 ¥300，年化投入约 ¥3,600。
      风险等级 B（建议控制预算）。
```

### 场景 2：预算管理
```
用户：「我一年花多少钱？」
系统：本月已投入 ¥450，月预算 ¥500，预算占比 90%。
      距离超额还剩 ¥50，请注意控制。
```

### 场景 3：历史复盘
```
用户：「帮我复盘一下」
系统：过去一年投入 ¥936，中奖 ¥128，净收益 -¥808。
      最高投入周期：8 月（¥156）。建议减少追号频率。
```

## 5. 行为风险等级

| 等级 | 判断 | 建议 |
|------|------|------|
| A | 月投入 ≤ 100 或频率低 | 保持理性 |
| B | 月投入 100-500，频率中等 | 控制预算 |
| C | 月投入 500-1000，追号频繁 | 减少追号 |
| D | 月投入 > 1000 或大量追号 | 强烈建议止损 |

## 6. 架构

```
engine/
├── user_behavior/      # Phase 1 行为分析（BehaviorAnalyzer）
├── budget_manager/     # Phase 2 资金管理（BudgetPlanner）
├── personal_review/    # Phase 3 历史复盘（PersonalReviewEngine）
├── lottery_quant/report # Phase 4 报告升级（个人视角）
└── assistant/          # Phase 5 personal_analyze 工具
```

复用：TicketManager（票据数据）、UserMemory（偏好）、QuantReport（报告）。

## 7. 桌面入口

- 工作台：预算管理入口（Budget Health）
- 个人中心：我的票据/投入/中奖/风险/报告/趋势
- AI 助手：personal_analyze 工具
