# Atlas v4.2 产品策略：User Growth & Data Flywheel

> Phase 0 · 2026-08-03

---

## 1. 战略命题

**v4.1.1 让 Atlas「主动找用户」；v4.2 让用户「自愿留下来」。**

核心手段不是加更多分析模块，而是把用户每一次购彩行为变成数据资产，
再用自动服务（提醒/兑奖/复盘）把资产变回用户价值——形成**数据飞轮**：

```
保存票据 → 数据沉淀 → 自动服务（提醒/兑奖/复盘）→ 个人价值（档案/预算/年度报告）
      ↑                                                        ↓
      └────────────── 用户再次打开 ──────────── 保存更多票据 ←──┘
```

飞轮不转的根因只有一个：**用户不保存票据** → 无数据 → 无自动服务 → 无价值 → 不回来。

## 2. v4.1.1 用户路径断点分析

任务书给定路径：

```
打开APP → 查看首页 → 查看开奖提醒 → 兑奖 → 复盘
```

| 步骤 | v4.1.1 现状 | 断点 | 飞轮损失 |
|------|------------|------|---------|
| 1 打开 APP | 启动时桌面通知（ReminderNotifier） | 通知仅在启动瞬间发一次，无「为什么打开」埋点 | 不知道第一因 |
| 2 查看首页 | 6 指标价值面板 + 首次引导 | 首次用户无票据 → 引导停留在「输入号码」；保存动作无强引导 | **保存率低 = 飞轮不启动** |
| 3 查看开奖提醒 | 静态区块 + 桌面通知 | 提醒是「展示」不是「行动」：无一键直达兑奖；无提醒点击埋点 | 提醒点击率无数据 |
| 4 兑奖 | 手动输入号码 → 防错确认 | 已保存票据不能「自动匹配一键兑奖」；多步操作损耗 | 兑奖完成率低 |
| 5 复盘 | 个人复盘（手动触发） | 开奖后**无自动复盘**；用户不看结果就流失 | 复盘查看率低 |

**三大结构性断点（v4.2 必须补）：**

1. **数据不沉淀**：用户保存了票，但没有「我的档案」——累计购买/中奖/周期/常购彩种无人告诉他。
2. **服务不自动**：复盘靠用户手动点，开奖后系统不主动告诉结果。
3. **价值不可带走**：数据锁在 App 里，没有年度报告，用户不觉得「这是我的数据」。

## 3. 北极星指标（North Star Metric）

> **月活跃购彩记录用户数（Monthly Active Ticket-Recording Users, MATRU）**
>
> 定义：**当月内保存过 ≥1 张彩票的唯一用户数。**

为什么是它：
- 保存票据 = 数据飞轮的第一环，**唯一可被产品动作直接驱动的北极星**；
- 活跃/留存/付费都建立在「有数据」之上；
- 禁止用「开奖查询次数」「分析次数」当北极星——它们不产生数据资产。

## 4. 辅助指标体系

| 指标 | 定义 | 当前状态 | 目标 |
|------|------|---------|------|
| 彩票保存率 | 保存过≥1张用户 / 新用户 | 无埋点 | Phase 1 建立档案后 ≥40% |
| 周留存 | 第7天仍打开用户 / 第0天用户 | 无埋点 | ≥25% |
| 提醒点击率 | 点击提醒用户 / 收到提醒用户 | 无埋点 | ≥30% |
| 兑奖完成率 | 开奖后7天内确认/兑奖票据 / 已开奖票据 | 无埋点 | ≥60% |
| 复盘查看率 | 看过复盘用户 / 活跃用户 | 无埋点 | ≥50% |

> 五指标全部无埋点——v4.2 所有阶段必须把「可统计」作为验收项。

## 5. v4.2 阶段与飞轮的映射

| Phase | 交付 | 对应飞轮环节 |
|-------|------|-------------|
| P1 用户数据中心 | 个人彩票档案（累计购买/中奖/周期/常购彩种） | 数据沉淀 → 价值显性化 |
| P2 自动复盘系统 | 开奖后自动匹配票据并生成结果报告 | 自动服务 |
| P3 用户成长体系 | 购彩健康指数（预算/连续/复盘/风险，A/B/C） | 个人价值（健康） |
| P4 数据导出 | PDF 年度报告 | 个人价值（拥有数据） |
| P5 会员价值验证 | Atlas Premium（不卖预测） | 变现 |
| P6 用户测试 | 50 用户模拟（首开/首存/首提醒/首兑/30天） | 验证 |
| P7 产品审计 | 5 问审计 | 决策 |

## 6. 红线（延续）

- 禁止预测中奖 / 提高中奖概率 / 稳赚话术。
- 禁止新增大量分析模块（本 Sprint 全部力量投在数据飞轮）。
- 成长体系是「购彩健康」，**不是**「中奖能力」，更不是积分商城。

## 7. CEO 判断点（v4.2 之后，不立即 v4.3）

完成 v4.2 后必须停下回答三问，再决定是否 v4.3：

1. **用户是否愿意留下数据？** —— 若不保存彩票，Atlas 没有数据飞轮。
2. **用户是否愿意被提醒？** —— 若提醒没人点，留存失败。
3. **用户是否愿意付费？** —— 若只愿兑奖，商业模式需要调整。
