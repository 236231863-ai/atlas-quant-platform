# Atlas v4.2 Business Model：Atlas Premium 会员价值验证

> Phase 5 · 2026-08-03

---

## 1. 核心原则

**不销售预测。** 会员只解锁「数据服务」，不包含任何预测 / 选号 / 提高中奖概率功能（测试强制）。

## 2. 套餐定义

| 功能 | 免费版 | Atlas Premium |
|------|:------:|:-------------:|
| 基础兑奖（手动核对） | ✅ | ✅ |
| 票据保存 | ✅（100 张） | ✅ 无限历史 |
| 预算中心 | ✅ | ✅ |
| 购彩健康指数 | ✅ | ✅ |
| 自动提醒（桌面通知） | — | ✅ |
| 无限历史沉淀 | — | ✅ |
| PDF 年度报告 | — | ✅ |
| 高级复盘（自动 + 多期对比） | — | ✅ |

## 3. 定价建议（验证用，非最终）

- 免费：¥0
- **Premium：¥9.9/月**（建议值，需真实验证）
- 付费理由：不是「买中奖概率」，而是「买数据服务 + 省时间 + 拥有数据」

## 4. 价值主张（Why Pay）

1. **自动提醒**：每周 6 次开奖不用盯，Atlas 主动告诉你。
2. **无限历史**：票据永久沉淀 → 年度报告 / 复盘才完整。
3. **年度报告**：拥有自己的数据，可导出 PDF 带走。
4. **高级复盘**：开奖后自动生成结果报告。

## 5. 与 CEO 判断点 3 的呼应

> 用户是否愿意付费？

Premium 假设：**只有先「愿意留下数据」（保存）才能「被提醒」（体验价值）才可能「付费」（解锁沉淀）**。
付费不是第一目标——保存率与提醒点击率是第一目标。

- **48 场景通过**：套餐定义 / 权限矩阵 / 功能门控 / 持久化 / 红线（不卖预测）。
