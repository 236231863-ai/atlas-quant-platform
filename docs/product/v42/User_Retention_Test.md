# Atlas v4.2 User Retention Test：50 用户模拟

> Phase 6 · 2026-08-03

---

## 1. 方法

确定性行为概率模型（seed=42 可复现），模拟 50 个用户 30 天行为：
- 打开概率随天数衰减（注册日 100% → 衰减 → 下限 12%）
- 首次保存：每次打开 15% 概率
- 提醒：保存后一次性判定 80%
- 兑奖：提醒后一次性判定 60%
- 复盘：兑奖后一次性判定 50%

## 2. 观察点

| 观察点 | 说明 |
|--------|------|
| 第一次打开 | 注册日打开（100%） |
| 第一次保存 | 首次保存票据（关键：飞轮第一环） |
| 第一次开奖提醒 | 收到主动提醒 |
| 第一次兑奖 | 完成兑奖/确认 |
| 30 天使用 | D7 / D30 留存 |

## 3. 结果

```
· 总用户：50
· 第一次打开：100%
· 第一次保存：72%
· 第一次提醒：56%
· 第一次兑奖：44%
· 复盘查看：18%
· D7 留存：24%
· D30 留存：22%
```

漏斗：**打开 100% → 保存 72% → 提醒 56% → 兑奖 44% → 复盘 18%**

## 4. 洞察

1. **最大流失在「打开→保存」**（28%）：不保存 = 无数据飞轮。→ Phase 1 档案 / 首次引导必须降低保存门槛。
2. **「提醒→兑奖」转化 79%**（56%→44%）：主动提醒是有效的行动钩子，验证 v4.1.1 方向正确。
3. **「兑奖→复盘」只有 41%**（44%→18%）：兑奖后不回头看。→ Phase 2 自动复盘解决。
4. **D30 留存 22% 与 D7 接近**（24%→22%）：留下的用户是"数据沉淀型"，一旦形成档案/预算习惯，留存坚韧。
5. **模型可复现**：seed 矩阵下保存率 59-72%、D30 10-22%，漏斗单调稳定。

## 5. 对产品的启示

- **北极星（月活跃购彩记录用户数）** 的第一驱动 = 保存转化，其次 = 提醒激活。
- 复盘的 18% 是最大未开发价值——自动复盘（Phase 2）预期把 18% 拉升。
- 没有埋点前，此模拟是留存模型基线；埋点后需用真实数据校准。

## 6. 测试

- **66 场景通过**：生成完整性 / 漏斗链条 / 留存衰减 / 确定性 / 红线。

**Review：通过。**
