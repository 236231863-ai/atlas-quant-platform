# Atlas Value Proposition — v3.7.0

> 价值主张：我们为用户创造什么价值，凭什么持续使用。

---

## 1. 价值主张一句话

**「用真实数据，做诚实分析，拿得出报告」** —— Atlas 让彩票数据分析从"玄学"变成"看得见的方法"。

## 2. 价值层次

| 层次 | 价值 | 对应功能 |
|------|------|----------|
| 功能价值 | 看数据、做图表、跑回测、出报告 | 6 大页面 + 导出 |
| 信任价值 | 数据真实（1000+期）、方法诚实（样本外/随机基准） | DataCenter v3 + Evaluation v2 |
| 习惯价值 | 每天有新的数据变化值得看 | Daily Intelligence |
| 情感价值 | "我不是在赌，我是在研究" | 诚实免责 + 专业感 |

## 3. 差异化（vs 竞争对手/替代方案）

| 替代方案 | 劣势 | Atlas 优势 |
|----------|------|-----------|
| 彩票网站走势图 | 只有图、不可导出、不诚实 | 数据+统计+回测+导出 |
| Excel 自己分析 | 门槛高、数据难找 | 开箱即用、内置 1000+ 期 |
| "必中"类 App | 骗局、违规 | 诚实声明、可信等级 |
| 通用 BI 工具 | 不面向彩票、学习成本高 | 专为彩票数据设计 |

## 4. 用户获得的完整价值闭环

```
安装（双击 Setup）→ 首次引导（3 步）→ 第一份报告自动生成（FirstSuccessFlow）
  → 每天看数据变化（Daily Intelligence）→ 周末回测策略（可信方法）
  → 导出报告带走（MD/PDF/CSV/PNG）→ 持续使用（数据更新 + 反馈学习）
```

## 5. 付费价值锚点（v3.7.0 铺垫，v4.0 落地）

| Edition | 价值 | 目标用户 |
|---------|------|----------|
| Community（免费） | 基础分析 + 1000 期数据 | 研究用户 |
| Professional（付费） | 双彩种 + 每日智能 + 导出全格式 | 高频用户 |
| Research（高阶） | 专业功能 + 优先支持 | 专业用户 |

> v3.7.0 实现 edition 框架与 feature flag，v4.0 收费落地。

## 6. 衡量价值是否成立

- 用户第一次打开 **5 分钟内**产出第一份分析 → 成立
- 用户 **7 天后还在用**（留存）→ 成立
- 用户 **愿意导出并分享** 报告 → 成立
- 用户 **愿意为 Professional 付费** → 成立（v4.0 验证）
