# Atlas User Journey Map — v3.8.0

## 1. 完整旅程

| 阶段 | 用户动作 | 产品响应 | 数据生成 |
|------|----------|----------|----------|
| 获取 | 下载/安装 | 安装向导 | 安装事件 |
| 首次 | 三步引导 → 自动报告 | 引导 + 第一份报告 | APP_START, ANALYSIS_RUN |
| 每日 | 打开看数据/摘要 | Dashboard + 每日摘要 | APP_START |
| 分析 | 看图/回测/导出 | 图表/回测/导出 | ANALYSIS_RUN, BACKTEST_RUN, REPORT_EXPORT |
| 反馈 | 提交问题/建议 | 反馈中心 | FEEDBACK_SEND |
| 留存 | 持续使用 | 成就/历史 | STRATEGY_SAVE |

## 2. 关键触点（v3.8.0 强化）

1. **首次成功**：5 分钟内出第一份分析（已有）。
2. **每日回访**：数据/统计变化有「新东西可看」（已有每日摘要）。
3. **价值感知**：Personal Dashboard 展示「我的研究等级/价值分」（新增）。
4. **AI 建议**：基于行为给出下一步建议（新增）。

## 3. 流失风险点
- 首次 3 分钟内未完成分析 → 需要 AI Suggestions 引导。
- 7 天未回访 → 无推送能力，靠价值感知留存。

## 4. 数据 → 决策
- 每个触点产生行为数据 → 价值分 → 产品迭代决策。
