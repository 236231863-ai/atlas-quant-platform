# Atlas v4.9.1 — Beta-0 用户反馈问卷（Feedback Questionnaire）

> 阶段：Beta-0（10 人种子测试 · 7 天）· 采集方式：产品负责人线下收集 → 录入系统
> 目的：采集用户对易用性、不可替代性、提醒价值、付费意愿的真实反馈

---

## 一、问卷设计

### Day3（第 3 天收集）

| 问 | 题目 | 选项 |
|----|------|------|
| **Q1** | 第一次使用是否容易？ | A 非常容易 / B 容易 / C 一般 / D 困难 / E 非常困难 |
| **Q2** | 如果 Atlas 消失，你是否会觉得不方便？ | A 会·怕忘兑奖 / B 会·需管理记录 / C 会·需历史分析 / D 不会·微信即可 / E 不会·没价值 |
| **Q3** | 开奖提醒是否有价值？ | A 很有价值 / B 有价值 / C 一般 / D 无价值 |

### Day7（第 7 天收集）

| 问 | 题目 | 选项 |
|----|------|------|
| **Q4** | 是否愿意继续使用 Atlas？ | A 愿意 / B 视情况 / C 不愿意 |
| **Q5** | 如果 Atlas 提供高级服务，你愿意支付？ | 0 元 / 3 元/月 / 6 元/月 / 9 元/月 / 12 元/月 |

### 用户原话（每问附）

> 每次收集请让用户**补充一句原话**（如"希望可以拍照识别彩票"、"提醒很有用"），用于报告「用户原话整理」。

---

## 二、采集方式（产品负责人执行）

### 方式 1：线下/群聊收集（推荐）
- 第 3 天向 10 人发 Q1-Q3 + 原话
- 第 7 天向 10 人发 Q4-Q5 + 原话
- 用表格记录每人答案

### 方式 2：系统录入（埋点 feedback_submitted）
用户在反馈入口提交的反馈会记录为 `feedback_submitted` 事件（source=MOBILE），但问卷答案建议线下收集后人工登记。
