## 三、策略核心结论（8 部分概要）

| 部分 | 结论 |
|------|------|
| 〇 战略第一问 | **验证阶段不做 APP**，用微信小程序验证价值 |
| 一 场景分析 | S1 录票 / S2 查开奖 / S5 兑奖提醒 = 手机端不可替代核心 |
| 二 三方案比较 | 微信小程序 **43** / Web **34** / iOS **24** → 小程序胜 |
| 三 最低成本 MVP | 只做 3 件事：录号码 / 自动查奖 / 简单记录（2-3 周） |
| 四 50 人测试 | 微信一键授权 + U 编号 + 每日记录沿用 |
| 五 埋点复用 | **一套事件集**，新增 `MOBILE` 来源并入真实统计，桌面埋点不动 |
| 六 14 天指标 | 首次保存率≥50% · D7≥30% · Q2 不便≥60% |
| 七 成功路线图 | 小程序 → 云端 → PWA/原生 iOS 决策点（数据驱动） |
| 八 失败标准 | Q2<60% 或 D7<30% → 停止手机端扩展，回归桌面 |
