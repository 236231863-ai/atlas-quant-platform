# Atlas v4.9.1 — P2 种子用户招募材料（Recruitment Kit）

> 状态：✅ 可分发 · 供产品负责人复制到彩票交流群 / 朋友圈
> 目标：招募 50–100 名 **A 类真实购彩者**，14 天验证「真实购彩者是否愿意每周打开 Atlas」
> 红线：本材料只面向真实用户，禁止模拟/自动生成/压测数据

---

## 一、一句话定位（对外话术）

> **Atlas —— 帮购彩者管好每一注彩票：自动兑奖、开奖提醒、资产复盘。**

---

## 二、招募对象（A 类用户）

| # | 画像 | 为什么适合验证 |
|---|------|--------------|
| A1 | 每周固定买大乐透 / 双色球 | 核心用户，留存验证主力 |
| A2 | 长期购彩但经常忘了查开奖 | 验证「自动兑奖 + 提醒」价值 |
| A3 | 想管住彩票花费的人 | 验证「资产中心 + 预算」价值 |
| A4 | 复式 / 胆拖玩家 | 验证「多注录入 + 兑奖」价值 |

**非招募对象**：不买彩票的人、只买一次的人、号码预测爱好者（无法验证核心价值）。

## 三、邀请话术（可复制）

### 版本 1：发给朋友（私聊）

```
兄弟，我最近在做一个叫 Atlas 的彩票管理软件（Windows 桌面版）。
它能帮我自动记下每一注彩票、开奖自动提醒、中了自动兑奖，不用再对着开奖号码挨个翻。

现在在找 50 个真实用户做 14 天免费体验验证（不是卖东西，就是帮我看看这东西有没有用）。
你如果平时会买大乐透/双色球，想试试的话加我，我给你装一个。
```

### 版本 2：发到彩票交流群

```
【真实用户招募 · Atlas 彩票管家体验】
各位彩友，我在验证一个 Windows 彩票管理工具 Atlas：
✅ 录彩票（号码粘贴/批量导入）→ 开奖自动提醒 → 中奖自动兑奖
✅ 每月/每周账目复盘，知道自己到底花了多少、中了多少
❌ 不做号码推荐、不做预测（那都是假的）

现在招募 50 位真实购彩者免费体验 14 天，帮忙回答 3 个问题：
你为什么用 / 为什么留下 / 愿不愿意付费。
有意愿的群友直接找我，我发安装包 + 使用说明。
```

### 版本 3：一对一引导（首次使用）

```
Atlas 安装好后打开，按这几步（1 分钟）：
1. 首次打开会引导你「建立我的彩票档案」→ 点开始
2. 选择「手动添加彩票」→ 把最近买过的号码粘贴进去（或先录 1 张试试）
3. 在设置里开启「开奖提醒」
4. 首页就能看到：几张票、什么时候开奖、中没中

之后它会自动帮你：开奖前提醒 → 开奖后核对 → 中奖了告诉你。
```

## 四、隐私与合规说明（务必告知用户）

- ✅ 彩票数据**仅保存在用户自己的电脑**（本地 `~/.atlas/`），不上传
- ✅ 行为数据仅用于**产品价值验证**（本次实验），不含姓名/手机号等身份信息
- ✅ 实验期间**不收费**，结束后可自行卸载
- ❌ 本软件**不做任何中奖预测 / 号码推荐**，彩票开奖结果随机，任何号码理论概率相同

---

## 五、用户编号分配

每位真实用户由产品负责人通过内部工具注册，分配稳定编号：

```
U0001, U0002, ..., U0050, ...
```

**用户无需知道自己的编号**，编号仅用于实验统计与留存追踪（禁止匿名统计）。
