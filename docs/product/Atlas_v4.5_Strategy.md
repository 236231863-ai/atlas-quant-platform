# Atlas v4.5 产品策略（Product Strategy）

版本：v4.5 · 可信开奖数据与用户留存系统 · 2026-08-04

## 一句话定位

**Atlas 帮用户管理每一张彩票：开奖自动提醒、自动兑奖、长期复盘。**

## 核心原则

本 Sprint **不新增娱乐功能**。优先解决：
1. **数据可信** —— 官方源 + 多重校验 + 防覆盖
2. **自动提醒可靠** —— 关闭软件仍收到开奖/中奖/待兑奖提醒
3. **用户回来理由** —— 自动兑奖 + 长期复盘 + 行为洞察

## 禁止

- ❌ 彩票预测
- ❌ 推荐中奖号码
- ❌ 提高中奖概率 / 稳赚等表达
- ❌ 新增无入口模块

## 用户问题（v4.5 回答）

| 问题 | 方案 |
|------|------|
| 我为什么相信开奖数据？ | DataProvider（官方/备用/本地）+ 校验 + DataHealthReport |
| 为什么关软件也能收到提醒？ | Windows 后台通知（计划任务 + Toast） |
| 兑奖结果可信吗？ | 报告含数据来源/期号/更新时间/校验状态 |
| 我为什么每天打开？ | 自动兑奖 + 长期复盘 + 行为报告 |

## 验收标准（v4.5）

1. 关闭软件后仍能收到开奖提醒 ✅
2. 开奖数据更新后自动触发兑奖 ✅
3. 错误数据不能覆盖正确数据 ✅
4. 大乐透和双色球分别使用正确数据源 ✅
5. 用户输入「我昨天的彩票中奖了没有？」自动判断/查询/生成报告 ✅

## Phase 规划

| Phase | 内容 |
|-------|------|
| P0 | 产品冻结 |
| P1 | engine/data_center：DataProvider + 校验 + DataHealthReport |
| P2 | engine/draw_monitor：开奖日监控 |
| P3 | Windows 后台提醒 |
| P4 | 兑奖信任升级 |
| P5 | 用户行为埋点 + User Behavior Report |
| P6 | Red Team Review |
| P7 | 7 份交付报告 |

每 Phase 先输出 Product Review，停止开发等待检查。
