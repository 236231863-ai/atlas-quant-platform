# Atlas v4.8 产品策略（Product Strategy）

版本：v4.8 · 解决用户冷启动 · 2026-08-05

## 定位升级

**从「用户有彩票数据后分析」→「帮助用户快速建立彩票资产档案」。**

## 首次体验目标

- **30 秒理解价值**
- **5 分钟建立资产**

## 新用户路径

```
打开软件
  ↓
选择建档方式：
  1. 已有彩票记录
  2. 手动添加历史
  3. 从照片识别彩票（OCR，人工确认）
  4. 从文本导入
  ↓
生成：我的彩票档案
```

## 核心原则

- 禁止：中奖预测 / 号码推荐 / 提高中奖概率
- 所有功能围绕：**记录、管理、复盘**

## Phase 规划

| Phase | 内容 |
|-------|------|
| P0 | 产品冻结 |
| P1 | 彩票数据导入中心（engine/import_center） |
| P2 | 票面 OCR 识别（ticket_ocr，人工确认） |
| P3 | 新用户引导系统（建档案→看购彩→开提醒） |
| P4 | 个人彩票档案卡（Profile Card） |
| P5 | 数据质量系统（A/B/C 可信等级） |
| P6 | AI 助手融合 |
| P7 | Red Team |

## CEO 验收 5 问

1. 新用户第一次打开有没有价值？
2. 5 分钟能否建立个人彩票档案？
3. 没有历史数据是否还能留下？
4. 为什么用户第二周回来？
5. 是否产生付费理由？

每 Phase 输出 Product Review + 用户价值验证 + 测试报告 + 桌面入口验证。
