# Lottery Quant Intelligence Layer — 产品设计

> 版本：v3.9.0
> 日期：2026-08-02
> 状态：已冻结（Phase 0）

---

## 1. 产品定位

Atlas 从「彩票兑奖工具」升级为「彩票量化分析助手」。

**核心用户价值**：用户购买彩票后，可以：
1. 保存投注组合
2. 分析号码结构
3. 查看概率模型
4. 模拟中奖覆盖
5. 评估资金风险
6. 回测投注策略
7. 生成量化报告

## 2. 产品边界（重要）

### ✅ 提供
- 统计分析（奇偶/大小/区间/和值/跨度/连号）
- 概率计算（理论概率模型）
- 历史研究（历史开奖分布/偏离度）
- 风险管理（资金投入/亏损概率/风险等级）
- 结构优化（组合重复率/相关性/覆盖范围）

### ❌ 禁止（红线）
- 「预测中奖号码」
- 「提高中奖概率」
- 「稳赚」
- 「人工智能预测彩票」
- 任何暗示号码组合能提高中奖可能性的表达

### 所有输出必须包含
> 彩票开奖结果具有随机性。系统只提供统计分析、概率计算、历史研究、风险管理。

## 3. 用户场景

| # | 场景 | 用户输入 | 系统响应 | 入口 |
|---|------|---------|---------|------|
| 1 | 结构分析 | 「我的15注号码结构怎么样？」 | 组合评分（结构均衡度，非中奖概率）| 量化中心/组合评分 |
| 2 | 重复风险 | 「这15注有没有重复风险？」 | 重复率/相关性/集中风险 | 量化中心/组合分析 |
| 3 | 概率模拟 | 「历史模拟中奖概率如何？」 | Monte Carlo 模拟报告 | 量化中心/模拟报告 |
| 4 | 资金风险 | 「我一年买彩票风险多少？」 | 年度投入/最大损失/亏损概率/风险等级 | 量化中心/资金风险 |
| 5 | 策略研究 | 「这个选号方法历史表现如何？」 | 策略回测 vs 随机基准 | 量化中心/策略回测 |

## 4. 场景示例

### 场景 1：号码结构
```
用户：「分析我这15注大乐透号码」
系统：
  🎯 组合评分：72/100
  说明：结构均衡（奇偶比、大小比、区间分布均在常见区间内）。
  注意：这是结构分析，不是中奖概率。开奖结果具有随机性。
```

### 场景 2：重复风险
```
用户：「这15注有没有重复风险？」
系统：
  号码重复率：65%
  风险提示：偏集中（前区 10、11、18 出现 ≥3 次）。
  建议：增加号码覆盖范围可优化组合结构，但不能保证中奖。
```

### 场景 4：资金风险
```
用户：「我一年买彩票风险多少？」
系统：
  年度投入：¥3,120
  最大损失：¥3,120（未中奖情形）
  预计回报：¥1,8xx（理论期望）
  亏损概率：99.xx%
  娱乐风险等级：C（建议控制投入）
```

## 5. 概率模型（Phase 1 概要）

- 大乐透一等奖理论概率：1 / C(35,5) / C(12,2) = **1/21,425,712**
- 双色球一等奖理论概率：1 / C(33,6) / C(16,1) = **1/17,721,088**
- 各奖级概率基于官方奖级规则计算（固定表）

**关键声明**：理论概率固定，任何号码组合概率相同。

## 6. 架构

```
engine/lottery_quant/
├── probability/     # 概率计算引擎
├── structure/       # 号码结构分析
├── simulation/      # 蒙特卡洛模拟
├── risk/            # 资金风险分析
├── portfolio/       # 投注组合分析
├── backtest/        # 策略回测（复用 evaluation_v2）
├── report/          # 量化报告生成（复用 export）
└── quant_director.py # 量化分析总控制器
```
