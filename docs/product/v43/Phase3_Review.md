## 产品价值

**「花钱有数」的管家价值落地**：用户不仅看到累计投入/中奖，还能看到**中奖率、净收益、亏损率、风险等级**——诚实展示负期望，帮用户看清自己的购彩行为并控制风险。这是长期信任的基础。

## 用户场景

- 老用户打开个人中心 → 看到「累计购买 ¥936 / 累计中奖 ¥128 / 净收益 -¥808 / 亏损率 86% / 风险等级 C（需关注）」→ 明确感知风险 → 调整预算。
- 年度报告：2025 年投入 ¥500 / 中奖 ¥30 / 活跃 5 个月。

## 技术实现

- `AssetReport`：win_rate = win_count/tickets，net = winnings − investment，loss_rate = max(0,−net)/investment，risk_level 基于亏损率阈值分级（A<60% / C<85% / D≥85%）。
- `annual_report`：按年过滤 + 中奖匹配（复用 PrizeCalculator）+ 活跃月统计。
- 修复：活跃月计算 `[:7]` 切片优先级 bug。

## 测试证明

- 资产字段矩阵：win_rate（0/0.5/1.0）、net（±）、loss_rate 边界
- 风险等级：全输→D、净收益正→A、中奖混合→B/C
- 年度报告：多年份/多月份/中奖矩阵
- cost 边界、双彩种、随机组合（20 seed）
