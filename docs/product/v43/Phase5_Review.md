## 产品价值

**用户打开 3 秒知道价值**：第一屏是「我有几张票 / 今晚有没有开奖 / 有没有待兑 / 本月花了多少」，而不是「平均和值 88.1」。研究指标（和值/奇偶/冷热）全部收敛到「数据分析」研究中心，首页只服务个人价值判断。

## 用户场景

- 周一晚上打开 Atlas → 第一屏：「🎫 我的票 3 张 / ⏰ 最近开奖 今晚大乐透 / 💰 待兑奖 2 张 / 📊 本月投入 ¥120」→ 3 秒确认"我该不该看开奖"。
- 不再需要研究指标的用户不会被"平均和值/奇偶比"干扰。

## 技术实现

- `_build` 重构：移除研究卡 + 冷热号面板 + 每日智能摘要区块；保留价值面板 → 数据概览 → 最近开奖表 → 研究指引。
- 价值面板/动态话术（`_value_metrics`/`_value_headline`）不变（v4.1 能力保留）。

## 测试证明

- 价值指标 6 项形状/数量矩阵
- 首页不含「平均和值 / 奇偶 / 88.1 / 3077」等研究数值
- 无票据引导 / 有票据不引导
- 动态话术矩阵（15 seed）
- 表格存在性 + 成本矩阵
