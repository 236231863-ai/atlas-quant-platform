## 产品价值

**从"假提醒"到"真提醒"**：用户保存票据后，开奖当天启动 Atlas → 桌面弹出提醒 + 事件记录。验收标准是**用户行为发生**（事件可查），不是页面存在。

## 用户场景

- 开奖前：首页看"距开奖 X 天"倒计时 → 回访理由。
- 开奖当天：桌面弹出"你的 N 张大乐透已开奖，X 张待兑奖" → 行为事件。

## 技术实现

- `EventTracker` 通用事件层（P2/P4 复用）：记录/统计/过滤用户行为。
- `DrawCountdown`：LotterySchedule 推算未来最近开奖日 → 天数/小时。
- `notify_and_record`：通知 + 事件原子化（无通知器也记录，保证事件完整）。
