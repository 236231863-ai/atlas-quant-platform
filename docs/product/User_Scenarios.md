# Atlas 用户场景库 — v3.8.0

> 定义普通用户的核心使用场景，指导产品设计。所有场景必须在桌面端可完成。

## 场景 1：买票后兑奖（核心）
- 用户：买了大乐透，想知道中了没。
- 流程：AI 助手输入号码 → 自动识别/兑奖 → 出奖金报告 → **保存票据**。
- 价值：不用记规则，不用查开奖。

## 场景 2：票据管理
- 用户：记不清买过哪些号码。
- 流程：工作台查看历史票据 → 按彩种/日期筛选。
- 价值：票据有归档。

## 场景 3：报告回顾
- 用户：上次兑奖结果是什么。
- 流程：报告中心查看历史兑奖报告。
- 价值：结果可追溯。

## 场景 4：追号观察
- 用户：想知道某个号多久没出（追号）。
- 流程：追号分析看遗漏统计（**非预测**）。
- 价值：满足好奇心，理性提示。

## 场景 5：每日工作台
- 用户：打开 Atlas 看今日概览。
- 流程：工作台 → 数据看板 + 我的票据 + 最近报告 + 建议。
- 价值：一个页面看所有。

## 场景 6：连续对话
- 用户：先报号码，再问"那我中了没"。
- 流程：AI 助手记住上文的号码。
- 价值：对话自然。

## 场景 7：记忆偏好
- 用户：偏好大乐透。
- 流程：记忆默认彩种，推荐优先大乐透。
- 价值：个性化。

---

**红线**：所有场景输出均为统计观察，禁止中奖预测/诱导。
