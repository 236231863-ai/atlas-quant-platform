# Atlas Product Positioning — v3.7.0

> 定位冻结日期：2026-08-02
> 原则：产品优先 > 技术炫技；真实用户价值 > 模块数量；稳定体验 > 架构扩张。

---

## 1. 一句话定位

**Atlas 是普通彩民与数据爱好者「看得懂、带得走」的彩票历史数据分析桌面工具**——内置真实历史数据、诚实的回测、可导出的报告，让每一次分析都有结论、有价值。

## 2. 定位三角

| 维度 | 定义 |
|------|------|
| 用户 | 有彩票数据好奇心、想用历史数据辅助判断的个人用户（非机构） |
| 场景 | 每天花 5-10 分钟看数据变化、周末研究策略回测、需要时导出报告 |
| 价值 | 用真实数据 + 诚实方法，替代"凭感觉选号"，让分析有据可查 |

## 3. 不是做什么（反定位）

- ❌ 不做中奖预测 / "必中"承诺（合规红线）
- ❌ 不做机构级研究平台（无云协作）
- ❌ 不堆概念模块（agent/ecosystem）
- ❌ 不做移动端（专注 Windows 桌面）

## 4. 产品阶段

| 版本 | 阶段 | 核心 |
|------|------|------|
| v3.6.1 | 可信工具 | 真实数据 + 诚实回测 + 可导出 |
| **v3.7.0** | **用户可持续使用** | 首次成功体验 + 每日循环 + 反馈学习 |
| v4.0 | 用户生态 | 用户 + 数据 + 报告 + 社区 + 收费 |

## 5. 成功指标（v3.7.0 验收）

- 首次用户 **5 分钟内完成第一次分析**
- 每日使用循环成立（Daily Intelligence 有价值）
- 700+ 测试通过，0 回归
- Windows 可安装、可运行、可导出
