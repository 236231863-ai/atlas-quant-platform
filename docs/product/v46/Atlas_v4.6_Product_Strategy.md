# Atlas v4.6 产品策略（Product Strategy）

版本：v4.6 · 真实用户运营验证阶段 · 2026-08-04

## 一句话定位

**帮购彩者管好每一注彩票。**

## 核心价值

1. **买了不会忘** —— 票据自动保存、到期提醒
2. **开奖自动知道** —— 后台提醒（关软件仍收）
3. **中奖自动发现** —— 自动兑奖 + 首页汇总
4. **花费有记录** —— 资产中心 + 月度复盘
5. **每月知道自己的彩票行为** —— 行为报告 + 月度净收益

## 禁止

- ❌ 新增号码推荐
- ❌ AI 预测中奖
- ❌ 提高中奖概率宣传
- ❌ 复杂研究指标首页展示

## 运营核心四问

| 问题 | v4.6 回答 |
|------|----------|
| 用户为什么打开？ | 首页兑奖汇总（待开奖/已中奖/待领取）+ 后台提醒 |
| 用户为什么回来？ | 月度复盘 + 行为报告 + 资产积累 |
| 用户为什么保存彩票？ | 保存第一张 → 自动兑奖 → 「已保护」价值闭环 |
| 用户为什么付费？ | Premium 解锁（自动兑奖提醒/年度报告/无限历史/家庭管理） |

## Phase 规划

| Phase | 内容 |
|-------|------|
| P0 | 产品冻结 |
| P1 | 用户事件分析系统（engine/user_analytics + 漏斗 + Retention Dashboard） |
| P2 | Windows 后台提醒（开奖前 24h/3h + 兑奖提醒，Task Scheduler） |
| P3 | 首次用户引导优化（30 秒价值理解 + onboarding 统计） |
| P4 | 自动兑奖体验优化（首页待开奖/已中奖/待领取） |
| P5 | 资产中心 2.0（年度净收益 + 月度复盘） |
| P6 | 商业化验证（Premium Feature Test + premium_view/click） |
| P7 | Red Team 审查 |

每 Phase 先输出 Product Review。
