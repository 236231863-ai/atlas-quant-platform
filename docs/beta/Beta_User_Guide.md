# Atlas Beta 用户指南（v3.7.1）

> 欢迎参与 Atlas Beta 测试！本指南帮助你快速上手并反馈问题。

---

## 1. 安装

- **安装包**：`AtlasQuant-3.7.1-beta-Setup.exe`，双击安装。
- **便携版**：解压 `AtlasQuant-3.7.1-beta.zip`，运行 `Atlas.exe`。
- 若 SmartScreen 提示，点击「更多信息」→「仍要运行」。

## 2. 首次使用（5 分钟上手）

1. **三步引导**：选用途 → 选彩种 → 选分析模式。
2. **自动生成第一份报告**：系统会生成并展示。
3. **数据看板**：查看 1200 期大乐透 + 500 期双色球数据。
4. **回测**：回测中心跑策略，看样本外 ROI 与随机基准。

## 3. 主要页面

| 页面 | 作用 |
|------|------|
| 📊 数据看板 | 数据概况 + 每日摘要 + 可信等级 |
| 📈 数据分析 | 频率/和值/跨度/奇偶图表 |
| 🧪 策略实验室 | 热号/冷号/均衡策略 |
| 📉 回测中心 | 诚实回测（样本外 + 随机基准） |
| 🤖 AI 助手 | 离线统计问答 / 在线大模型 |
| 📄 研究报告 | 一键生成 + 导出 |

## 4. 导出功能

- 报告：MD / PDF / CSV
- 回测：明细 CSV / 报告 PDF / 图表 PNG

## 5. 如何反馈

- 在软件内「帮助中心」提交反馈。
- 或直接发送邮件/群聊反馈：问题描述 + 复现步骤 + 截图。
