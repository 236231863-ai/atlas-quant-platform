# Atlas Beta 测试计划（v3.7.1）

> 目标：让 Atlas 成为可邀请真实用户体验的 Beta 产品。
> 原则：真实用户体验 > 数据反馈闭环 > 产品迭代能力。

---

## 1. Beta 目标用户

| 用户类型 | 描述 | 邀请渠道 |
|----------|------|----------|
| 彩票数据研究者 | 买大乐透/双色球，研究历史数据 | 彩票社区 / 论坛 |
| 数据分析学习者 | 想用真实数据练手 | 数据学习群 / 高校 |
| 高级玩家 | 有购彩经验，追求方法 | 玩家群 |

## 2. 测试目标

- 首次用户 **5 分钟**完成第一次分析。
- 收集真实使用数据（页面/功能/导出/回测）。
- 收集用户反馈（Bug / 功能请求 / 评分）。
- 验证安装 → 启动 → 分析 → 导出全链路。

## 3. 测试批次

| 批次 | 用户数 | 时长 | 目标 |
|------|--------|------|------|
| Beta 1 | 10-20 | 2 周 | 功能可用性 + 崩溃收集 |
| Beta 2 | 30-50 | 2 周 | 留存 + 反馈闭环 |
| Beta 3 | 100+ | 持续 | 规模化验证 |

## 4. 成功标准

- 无致命崩溃（app_open 到 app_close 成功率 > 95%）。
- ≥70% 用户完成首次分析。
- 收集 ≥30 条有效反馈。
- 反馈闭环：New → Reviewing → Fixed → Closed。

## 5. 风险与回滚

- 若 Beta 1 崩溃率 > 10%，暂停邀请，修复后再放量。
- 版本回滚：保留上一稳定版本（v3.7.0）安装包。

## 6. 版本

- Beta 版本：`v3.7.1-beta`
