# Atlas User Value Report — v3.8.0

> 用户价值量化报告（基于 value_score 五维评分）

## 1. 价值分模型

| 维度 | 权重 | 说明 |
|------|------|------|
| Usage | 20 | 事件量 + 活跃天数 |
| Retention | 20 | 活跃天数（目标 7 天）|
| Research | 20 | 分析/回测/策略保存 |
| Export | 20 | 产出导出 |
| Feedback | 20 | 反馈参与 |

总分 0-100 → 等级：入门/进阶/资深/专家。

## 2. 用户分层

| 等级 | 分值 | 特征 | 运营动作 |
|------|------|------|----------|
| 入门 | <35 | 新用户/低频 | AI 建议引导 |
| 进阶 | 35-60 | 开始使用核心 | 鼓励回测/导出 |
| 资深 | 60-80 | 高频活跃 | 推荐 PRO |
| 专家 | ≥80 | 深度用户 | 推荐 ENTERPRISE |

## 3. 价值→商业映射
- 高价值分用户 → 高付费意愿（引导 PRO/ENTERPRISE）。
- 低价值分 → AI Suggestions 提升留存。

## 4. 报告输出（Personal Dashboard）
用户可见：价值分/等级/五维雷达 → 激励持续使用。
