# Atlas Quant Platform - 项目章程

> 版本: 1.0
> 状态: 已批准
> 创建日期: 2026-07-28

---

## 1. 项目概述

- 项目名称: Atlas Quant Platform
- 项目代号: 阿特拉斯计划
- 项目类型: 开源量化研究平台
- 目标版本: v1.0.0
- 许可证: MIT

## 2. 项目愿景

**建立一个跨领域、插件化、引擎驱动的量化研究平台。**

平台的核心不是"预测"，而是"分析"——让研究人员能够通过历史数据回测、统计分析、策略优化，深入理解概率游戏的数学本质。

## 3. 核心原则

1. 学术诚实 - 绝不声称预测能力，所有结论标注置信区间
2. 引擎驱动 - 所有计算由引擎完成，UI永不直接计算
3. 插件化 - 每个彩种/品种是一个插件，不修改主程序
4. 策略即数据 - 策略是JSON，不是代码，可热加载
5. 层隔离 - UI→API→Service→Engine→Data→DB，严禁越层
6. 可复现 - 相同数据+相同策略=相同结果，种子可控

## 4. 范围

### 包含

- 历史彩票数据的采集、清洗、存储
- 统计分析引擎（频率、遗漏、趋势、分布）
- 回测引擎（历史数据模拟交易）
- 策略框架（JSON定义、组合、参数优化）
- 模拟引擎（蒙特卡洛模拟）
- 报告生成（PDF/HTML/CSV）
- AI辅助研究（大模型集成）
- 插件系统（可扩展的数据源和彩种）

### 不包含

- 实时投注或交易执行
- 任何形式的预测承诺
- 金融投资建议
- 非法赌博相关功能

## 5. 项目治理

项目发起人 -> 架构委员会 -> 核心贡献者 -> 社区贡献者

架构委员会职责: 审批所有ADR, 审查重大变更
核心贡献者职责: 维护代码库, 代码审查
社区贡献者职责: 提交PR, 报告Issue

## 6. 里程碑路线

- M1: 架构落地 v0.1.0 Week2 - 管理体系文档、项目骨架
- M2: 数据层 v0.2.0 Week5 - 数据采集、存储、查询
- M3: 引擎核心 v0.3.0 Week8 - 分析引擎、统计引擎
- M4: 回测系统 v0.4.0 Week11 - 回测引擎、策略引擎
- M5: 策略与优化 v0.5.0 Week14 - 策略实验室、参数优化
- M6: 界面与AI v0.6.0 Week18 - Web Dashboard、AI集成
- M7: 工程化 v0.7.0 Week20 - 性能优化、容器化、文档
- RTM: 正式版 v1.0.0 Week22 - 正式发布

## 7. 技术债务管理

- 每个 Sprint 分配 10% 时间偿还已知技术债
- PR 合并前必须通过所有质量门禁
- ADR 记录所有重大架构决策
- 每季度进行一次架构评审

## 8. 风险管理

- 数据源不稳定: 概率中, 影响高 - 多源冗余、适配器模式
- 性能瓶颈: 概率中, 影响中 - 早期基准、Sprint 7专项优化
- 范围蔓延: 概率中, 影响中 - 严格Sprint边界、MVP优先
- 法律法规: 概率低, 影响高 - 合规审查、免责声明
- 贡献者流失: 概率中, 影响中 - 文档完善、自动化流程

## 9. 质量目标

- 单元测试覆盖率 >= 80%
- 关键模块覆盖率 >= 90% (engine/core)
- mypy strict mode 零错误
- Ruff lint 零警告
- 接口100%有类型注解
- 关键路径 1000期数据回测 < 2s

## 10. 免责声明

Atlas Quant Platform 是一个学术研究工具。

- 所有分析基于历史数据，不代表未来表现
- 不提供任何形式的预测或投资建议
- 用户自行承担使用本软件的所有风险
- 请理性决策，量力而行
