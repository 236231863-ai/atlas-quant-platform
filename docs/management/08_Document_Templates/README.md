# Atlas Quant Platform - 文档模板

> 版本: 1.0
> 创建日期: 2026-07-28

---

## 1. ADR模板 (架构决策记录)

```markdown
# ADR-NNN: 标题

> 状态: [提案|已批准|已弃用|已替代]
> 日期: YYYY-MM-DD
> 决策者: [姓名]

## 背景
为什么需要做这个决策?

## 选项
列出考虑的方案。
- 方案A: ...
- 方案B: ...

## 决策
选择方案A。

## 理由
为什么选这个方案?
- 理由1
- 理由2

## 后果
采纳后的影响:
- 正面: ...
- 负面: ...

## 替代方案被拒绝的理由
- 方案B: 因为...
```

## 2. PRD模板 (产品需求文档)

```markdown
# PRD: 功能名称

> 版本: 1.0
> 状态: 草案

## 背景
为什么需要这个功能?

## 目标用户
- 用户类型1
- 用户类型2

## 功能需求
- FR1: ...
- FR2: ...

## 用户故事
- US1: 作为..., 我想..., 以便...
- US2: 作为..., 我想..., 以便...

## 验收标准
- [ ] AC1: ...
- [ ] AC2: ...

## 非功能性需求
- 性能要求
- 安全要求
```

## 3. RFC模板 (技术方案)

```markdown
# RFC: 标题

> 状态: [草案|讨论中|已采纳]
> 日期: YYYY-MM-DD

## 摘要
一句话描述。

## 动机
为什么需要这个变更?

## 设计方案
### 接口定义
### 数据流
### 错误处理

## 备选方案
### 方案B
被拒绝理由:

## 影响评估
- 向后兼容性
- 性能影响
- 安全影响
```

## 4. PR提交模板

```markdown
## 背景
相关Issue: #123

## 变更内容
- 变更1
- 变更2

## 测试方式
- [ ] 单元测试通过
- [ ] 集成测试通过
- [ ] 手动测试完成

## 影响范围
- 影响的模块
- 是否需要更新文档
```
