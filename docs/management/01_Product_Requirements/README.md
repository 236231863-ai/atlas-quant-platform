# Atlas Quant Platform - 产品需求文档 (PRD)

> 版本: 1.0
> 状态: 草案
> 创建日期: 2026-07-28

---

## 1. 产品定位

Atlas Quant Platform 是一个面向量化研究人员的开源分析平台。
目标用户: 数据分析师、彩票研究者、统计爱好者、量化开发人员。

## 2. 用户角色

### 研究人员 (Researcher)
- 浏览历史数据，执行统计分析
- 定义和测试策略
- 查看回测报告
- 使用AI辅助分析

### 策略开发者 (Strategy Developer)
- 创建和优化策略
- 编写自定义分析
- 导出研究数据

### 系统管理员 (Administrator)
- 管理数据源
- 监控系统状态
- 配置系统参数

## 3. 功能列表

### P0 - MVP (v1.0 必须)
- [x] 数据采集：从公开源自动采集历史开奖数据
- [x] 数据管理：存储、查询、导出历史数据
- [x] 频率分析：号码出现频率、期望频率对比
- [x] 遗漏分析：当前遗漏、最大遗漏、平均遗漏
- [x] 基础统计：和值、奇偶比、区间分布
- [x] 回测引擎：基于历史数据模拟策略收益
- [x] 策略定义：JSON格式创建和管理策略
- [x] 报告：生成分析报告 (CSV/HTML)
- [x] CLI：命令行界面操作
- [x] 插件系统：支持新增彩种插件

### P1 - 重要 (v1.0 应有)
- [ ] 趋势分析：移动平均、线性回归
- [ ] 参数优化：Grid Search/Bayesian Optimization
- [ ] 策略组合：AND/OR 逻辑组合
- [ ] Web Dashboard：交互式可视化界面
- [ ] AI分析助手：LLM驱动的自动分析
- [ ] 蒙特卡洛模拟：模拟大量随机场景
- [ ] 支持多种彩种 (双色球、大乐透、快乐8)

### P2 - 增强 (v1.0 后有)
- [ ] Desktop Client (Tauri)
- [ ] 体育数据插件
- [ ] 金融数据插件
- [ ] 社区策略市场
- [ ] 高级可视化 (交互式3D图表)
- [ ] 分布式回测

## 4. 用户故事

### 数据采集
US1: 作为研究人员，我想自动采集并存储历史开奖数据
US2: 作为研究人员，我想验证数据完整性和质量
US3: 作为管理员，我想配置多个数据源作为备份

### 统计分析
US4: 作为研究人员，我想分析号码出现频率
US5: 作为研究人员，我想查看号码遗漏情况
US6: 作为研究人员，我想分析趋势和分布
US7: 作为研究人员，我想导出分析结果为CSV/PDF

### 策略回测
US8: 作为策略开发者，我想用JSON定义策略规则
US9: 作为策略开发者，我想在历史数据上回测策略
US10: 作为策略开发者，我想评估策略的收益、风险和稳定性
US11: 作为策略开发者，我想对比多个策略的表现

### AI辅助
US12: 作为研究人员，我想用自然语言描述分析需求
US13: 作为研究人员，我想让AI自动生成分析报告
US14: 作为研究人员，我想让AI推荐可能的分析方向

## 5. 非功能性需求

### 性能
- 1000期数据回测完成 < 2s
- 页面加载 < 1s (API响应)
- 支持1000万+条历史记录

### 可靠性
- 数据采集99.9%成功率
- 回测结果100%可复现
- 系统可用性99.5%

### 安全性
- 敏感配置仅通过环境变量注入
- 所有输出附带免责声明
- 输入数据经过严格校验

### 可维护性
- 模块独立可测试
- API向下兼容
- 文档与代码同步更新

## 6. 验收标准

### 功能验收
- 每个用户故事有对应的自动化测试
- CLI命令可完整走通核心工作流
- 回测结果与手工计算结果一致

### 质量验收
- 单元测试覆盖率 >= 80%
- 集成测试覆盖核心路径
- mypy strict mode 通过
