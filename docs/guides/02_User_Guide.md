# User Guide

## 界面概览

桌面版左侧为导航栏，包含 6 个模块：

| 模块 | 功能 |
|------|------|
| **Dashboard 数据看板** | 总期数/最新开奖/奖池/和值等指标 + 冷热号 |
| **Data Analysis 数据分析** | 频率/和值/跨度/奇偶图表 |
| **Strategy Lab 策略实验室** | 热号/冷号/均衡策略卡片 |
| **Backtest Center 回测中心** | 策略回测 + ROI 曲线 + 明细 |
| **AI Assistant 智能助手** | 本地统计问答 |
| **Reports 研究报告** | 一键生成统计报告 |

## 常见操作

### 查看数据看板
启动后默认进入 Dashboard，可查看最新开奖与统计指标。

### 分析图表
点击「Data Analysis」，切换频率/和值/跨度/奇偶四个图表。

### 回测策略
在「Strategy Lab」点击「▶ 回测此策略」，自动跳转回测中心并运行。

### AI 咨询
在「AI Assistant」输入问题：
- "推荐下期号码"
- "热号有哪些"
- "奇偶分布如何"

### 生成报告
在「Reports」点击「🔄 生成统计报告」，报告可复制保存。
