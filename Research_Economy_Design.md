# Research Economy Design

## Overview
Economic system for agent-based research ecosystem.

## Components
- AgentEconomyEngine: Track agent scores (performance, contribution, knowledge)
- AgentScore: per-agent metrics with weighted overall score
- ReputationSystem: Long-term reliability (accuracy, success rate, collaboration)
- ResearchMarketplace: Task publishing, agent bidding, contract assignment

## Economy Flow
Agent Performance -> Economy Engine -> AgentScore
Agent History -> Reputation System -> Rank
Research Tasks -> Marketplace -> Bids -> Contracts -> Results
