# Atlas v4.3 商业化验证报告（Business Report）

> 2026-08-03 · 验证付费意愿，不写空洞商业计划

## 一、免费版 vs 会员（v4.3 验证模型）

| 功能 | 免费版 | Atlas Premium（会员） |
|------|--------|----------------------|
| 票据管理（保存/列表/删除） | ✅ | ✅ |
| 兑奖提醒（桌面通知） | ✅ | ✅ |
| 自动兑奖 + 待兑奖列表 | ✅ | ✅ |
| 预算中心（周/月/年 + 预警文本） | ✅ | ✅ |
| **历史报告**（全部期复盘） | ⚠️ 最近 30 天 | ✅ 无限 |
| **年度分析**（年度 Atlas Report / 资产年报） | ⚠️ 当年 | ✅ 全部年份 |
| **家庭预算**（多人/多账户预算） | ❌ | ✅ |
| 高级复盘（逐注 + 导出 PDF） | ❌ | ✅ |
| 提醒频率 / 批量导入 | 基础 | 增强 |

**原则**：免费版完成「保存→提醒→兑奖」核心闭环（不挡住核心价值）；会员解锁**历史/分析/家庭**增值。

## 二、付费意愿验证（基于 P6 红队 10 用户 + 真实事件）

| 能力 | 付费意愿 | 目标用户 | 依据 |
|------|---------|---------|------|

| 数据分析教程 | ⭐ | 学习者 | 人群小 |

## 三、定价模型（建议）

| 档位 | 价格 | 内容 | 验证状态 |
|------|------|------|---------|
| **Free** | ¥0 | 票据管理 + 兑奖提醒 + 待兑奖 | 已验证核心闭环 |
| **Premium 月度** | ¥9.9/月 | 无限历史 + 年度分析 + 高级复盘 + 增强提醒 | 待 A/B 验证 |
| **Premium 年度** | ¥79/年 | 同月度（约 7 折） | 待验证 |
| **家庭版** | ¥19.9/月 | 家庭预算 + 多账户 | 长尾（小样本） |

**红线**：任何档位都不卖「预测 / 推荐号码」。付费 = 数据服务 + 自动化，不是中奖承诺。

## 四、关键验证指标（商业验证期）

| 指标 | 目标 | 现状 |
|------|------|------|
| 免费→会员转化率 | ≥5% | 未上线，无数据 |
| 免费版 7 日留存 | ≥30% | 无埋点，待验证 |
| 提醒点击率 | ≥30% | 无埋点，模拟 79% |
| 票据保存率 | ≥40% | 无埋点，模拟 72% |

## 五、验证前提（下一 Sprint 唯一目标）

**没有埋点就没有商业化数据。** v4.4 必须先补核心埋点（ticket_saved / reminder_click / claim_viewed / report_viewed / budget_alert），跑 7-30 天真实数据，回答：
1. 用户是否愿意留下数据？（票据保存率）
2. 用户是否愿意被提醒？（提醒点击率）
3. 用户是否愿意付费？（转化率）

**结论**：商业化模型清晰（免费核心 + Premium 增值），但**验证前置条件是埋点**。当前不做收费上线。
