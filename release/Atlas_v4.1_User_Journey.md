# Atlas v4.1 阶段6：真实用户测试 — User Journey

> 10 个真实角色用户 · 完整路径 · 2026-08-03

---

## 角色与旅程

### 1. 新手小白（首次接触彩票）
```
打开 Atlas → 首页「欢迎！输入你的第一注彩票」→ 输入号码 → 防错确认「是否按8/1算？」
→ 回复「是的」→ 看到兑奖报告 → 提示「保存下来我帮你管」
✅ 30 秒完成「输入→得到结果」闭环
```

### 2. 老用户（购彩多年）
```
打开 Atlas → 首页显示「今日开奖/待兑奖」→ 点击今日提醒 → 逐注查看中奖
→ 个人中心查看累计投入/中奖 → 年度报告回顾
✅ 3 秒知道今天该做什么
```

### 3. 倍投用户（追号成瘾风险）
```
打开 Atlas → 首页「你追的 [10 11 18 22 35] 已连续 2 期」→ 预算预警「本月超支」
→ 复盘「净收益 -¥808」→ 提示控制追号
✅ 追号提醒 + 亏损率让行为可见
```

### 4. 理性购彩者（有预算）
```
设置月预算 ¥300 → 每期记录票据 → 预算中心看周/月/年占比
→ 超 80% 收到预警 → 控制投入
✅ 预算管家（省钱价值）
```

### 5. 筹建方（组织合买）
```
管理多张票据 → 量化中心分析组合 → 复盘投入收益 → 分享年度报告
✅ 票据系统 + 组合分析
```

### 6. 分析党（研究号码）
```
数据分析 → 冷热号/和值/跨度 → 回测中心策略 → 量化中心组合评分
✅ 统计工具链完整
```

### 7. 收藏党（收集记录）
```
保存每期票据 → 个人中心看连续购买天数 → 月度趋势 → 年度报告仪式感
✅ 数据积累 + 成长记录
```

### 8. 兑奖党（只关心中没中）
```
开奖日 → 首页「今日开奖」→ 输入/查看票据 → 自动兑奖
✅ 最高频场景最快到达
```

### 9. 长期用户（已用 1 年）
```
个人中心 → 年度报告「今年投入 ¥936 / 中奖 ¥128」→ 趋势回顾 → 设置新预算
✅ 数据飞轮（越用越准）
```

### 10. 完全小白（从未买彩票）
```
打开 Atlas → 首页欢迎 → AI 助手「大乐透是什么/怎么玩」→ 了解开奖节奏
✅ 引导式上手
```

## 总结

| 维度 | 结论 |
|------|------|
| 新手闭环 | ✅ 30 秒「输入→结果」|
| 老用户留存 | ✅ 今日提醒/待兑奖 |
| 风险用户 | ✅ 追号/亏损率预警 |
| 付费潜力 | ✅ 预算管家 + 自动兑奖 |
| 数据飞轮 | ✅ 年度报告 + 连续记录 |
