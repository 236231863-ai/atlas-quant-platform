# Atlas v4.5 用户手册（User Manual）

版本：v4.5.0 · 2026-08-04

## 一、开奖数据可信吗？

**可信。** Atlas 从官方体彩 API 拉取开奖，经过**校验**（期号递增/日期/号码数量/范围）后才写入本地，**错误数据不会覆盖正确数据**。你可以随时看到数据状态：

```
🩺 开奖数据健康报告
· 大乐透：最新期 26087 · 2026-08-03 · 来源 官方数据 · 状态 可信
· 双色球：最新期 2026087 · 2026-07-30 · 来源 内置 · 状态 可信
```

## 二、关闭软件还能收到提醒吗？

**能。** 安装 Atlas 后，Windows 后台任务每 30 分钟自动检查开奖，软件关闭时也能收到：
- 🔔 开奖提醒（开奖日）
- 🎉 中奖提醒（你的彩票中奖时）
- 🧾 待兑奖提醒（有已开奖未查看的票据）

> 通知通过 Windows 通知中心弹出；若系统禁用，则降级为消息框/通知日志（`~/.atlas/notifications.jsonl`）。

## 三、兑奖报告为什么可信？

每份兑奖报告标注**数据信任信息**：

```
🎫 兑奖报告 · 开奖期 26086 · 号码来源 官方数据 · 数据更新 2026-08-04 09:00 · 状态 已验证
```

- **号码来源**：官方数据 / 本地缓存
- **更新时间**：数据拉取时间
- **状态**：已验证（缓存中存在该期号）

## 四、数据健康等级

| 状态 | 含义 |
|------|------|
| 可信 | 12 小时内已同步 |
| 过期 | 超过 12 小时未更新（B/C 级提示） |
| 异常 | 无法读取/无数据 |

## 五、常见问题

- **Q：双色球数据为什么没更新？** 官方双色球接口（gameNo=235）当前返回空，Atlas 保持内置 500 期有效数据，大乐透实时正常。
- **Q：如何查看我的行为报告？** 数据分析页/个人中心可查看 User Behavior Report（保存/提醒/兑奖/报告行为统计）。

## 六、免责声明

彩票开奖结果具有随机性。Atlas 提供开奖同步、自动兑奖与风险管理，不预测中奖，不承诺收益。
