# Atlas Quant Platform v3.6.1 用户手册

> 彩票数据分析工具 · 520 期真实历史数据 · 本地离线运行

---

## 1. 界面总览

启动后主界面 = 左侧导航（6 个功能页）+ 右侧内容区。

| 页面 | 图标 | 功能 |
|------|------|------|
| 数据看板 | 📊 | 数据概况：期数/最新期/奖池/平均和值/最高频号码 |
| 数据分析 | 📈 | 频率 / 和值 / 跨度 / 奇偶 四类图表 |
| 策略实验室 | 🧪 | 热号追击 / 冷号潜伏 / 奇偶均衡 三种策略 |
| 回测中心 | 📉 | 策略历史回测：样本内外 ROI / 随机基准 / 逐期明细 |
| AI 智能助手 | 🤖 | 本地统计问答（离线）或大模型对话（在线） |
| 研究报告 | 📄 | 一键生成统计报告，可导出 MD/PDF/CSV |

---

## 2. 数据看板

- **指标卡**：总期数、最新期号、最新奖池、平均和值、最高频号码。
- **可信等级**：A（≥500 期）/ B（≥200）/ C（≥50）/ D（<50）。当前内置大乐透 **520 期，等级 A（可信）**。
- **数据不足警告**：若数据 <500 期，看板会以红色提示。

---

## 3. 数据分析

点击上方按钮切换图表类型：
- **频率分布**：前区号码出现次数直方图。
- **和值分布**：每期前区和值分布。
- **跨度分布**：前区最大值-最小值分布。
- **奇偶分布**：前区奇偶比例。

---

## 4. 策略实验室

| 策略 | 说明 |
|------|------|
| 🔥 热号追击 | 追踪近期高频号码 |
| 🧊 冷号潜伏 | 关注长期未出号码 |
| ⚖️ 奇偶均衡 | 前区奇偶按 3:2 配置 |

点击「▶ 回测此策略」→ 自动跳转回测中心并运行。

> ⚠️ 彩票开奖为随机事件，策略仅供研究参考，不构成购彩建议。

---

## 5. 回测中心

1. 选择策略 → 点「▶ 运行回测」。
2. 结果包含：
   - 总收益率 / 样本内 ROI / **样本外 ROI**（前 70% 训练，后 30% 验证）
   - **随机基准对照**：随机选号同口径回测的 ROI 均值与 90% 区间
   - 超额收益、最大回撤、逐期命中明细表
3. **导出**：⬇ 明细 CSV / ⬇ 报告 PDF / ⬇ 图表 PNG。

> 结论说明：策略收益若未高于随机基准 90% 区间，表示统计上无优势。

---

## 6. AI 智能助手

### 离线模式（默认）
直接输入问题，支持：
- 「推荐下期号码」（热号/冷号/均衡）
- 「热号有哪些」「冷号有哪些」
- 「奇偶分布 / 和值 / 跨度情况」
- 「奖池数据概览」

### 在线模式（可选）
1. 点击「⚙ 配置 API」。
2. 填入 DeepSeek API Key，保存。
3. 切换在线模式，使用真实大模型对话。

---

## 7. 研究报告

1. 点「🔄 生成统计报告」→ 自动生成完整分析（概览/频率/冷热号/后区/策略推荐/免责）。
2. **导出**：⬇ Markdown / ⬇ PDF / ⬇ CSV。

---

## 8. 数据导入

内置 520 期大乐透真实历史数据（2023-02 ~ 2026-08）。

**导入自己的数据**：
1. 准备 CSV，格式：`issue,date,numbers,pool`
   ```
   issue,date,numbers,pool
   26086,2026-08-01,10 11 18 22 35|06 12,813207389.58
   ```
2. 放入 `data/raw/` 或 `~/.atlas/data/`，命名 `dlt_history.csv`（大乐透）/ `ssq_history.csv`（双色球）。
3. 重启软件即可生效（用户数据优先于内置数据）。

---

## 9. 稳定性与日志

- 软件内置**全局异常处理**：异常自动写入日志。
- 崩溃后下次启动会提示「上次异常退出」，并提供日志目录。
- 日志位置：`C:\Users\你的用户名\.atlas\logs\`。
