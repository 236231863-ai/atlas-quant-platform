# Atlas v4.2 用户手册

> User Growth & Data Flywheel Sprint · 2026-08-03

---

## 1. 个人彩票档案（Phase 1）

打开 **个人中心**，顶部「我的彩票档案」显示：
- 累计购买（¥）/ 累计中奖（¥）/ 中奖次数 / 最高奖金
- 购买周期（月）/ 常购彩种（大乐透/双色球）

> 数据来自你保存的每一张彩票。保存越多，档案越完整。

## 2. 自动复盘（Phase 2）

开奖后启动 Atlas，自动弹出 **「📊 Atlas 自动复盘」** 桌面通知：
- 「你的 N 张大乐透已开奖」
- 「本期中奖 X 注，合计 ¥xxx」或「本期未中奖」
- 「本月累计投入 ¥xxx」「历史中奖 X 次」

> 只陈述已开奖事实，不预测未来。

## 3. 购彩健康指数（Phase 3）

个人中心「🌱 个人成长」区域显示 **理性等级 A/B/C**：
- 预算控制 / 连续记录 / 复盘习惯 / 风险意识 四维得分
- A=健康、B=良好、C=需关注

> 反映购彩行为习惯，**不代表中奖能力**。

## 4. PDF 年度报告（Phase 4）

个人中心点击 **「📄 导出年度报告」**：
- 选择保存位置 → 生成 `Atlas_2026_年度报告.pdf`
- 内容：购买次数 / 投入金额 / 中奖次数 / 最高奖金 / 每月投入 / 购彩习惯

## 5. Atlas Premium（Phase 5）

个人中心「💎 会员」卡片展示套餐：
- **免费版**：基础兑奖、票据保存（100 张）、预算中心、健康指数
- **Atlas Premium**：+自动提醒、无限历史、年度报告、高级复盘

> 会员只解锁数据服务，不包含任何预测功能。

## 6. 数据飞轮使用建议

1. 每次购彩后保存票据（AI 助手输入号码或工作台保存）。
2. 开奖后点开自动复盘通知看结果。
3. 月底看预算预警，年度末导出年度报告。
