# Atlas v4.1 阶段2：开奖提醒中心 — 产品报告

> Thread A 开发 + Thread B 审计 · 2026-08-03

---

## 1. 目标

回答「**今天为什么打开 Atlas**」：
- 开奖提醒：今天哪些彩种开奖
- 兑奖提醒：今天可兑奖的票据
- 未兑奖提醒：已开奖未确认的票据
- 遗漏提醒：追号组合连续期数

## 2. 实现

### engine/reminder_center/reminder.py（ReminderEngine）

| 能力 | 数据源 |
|------|--------|
| 今日开奖 | LotterySchedule（大乐透一/三/六 + 双色球二/四/日）|
| 可兑奖 | draw_date = 今天的票据 |
| 未兑奖 | draw_date < 今天 或 有购买日未结算 |
| 追号提醒 | 相同组合出现 ≥2 次的连续期数 |
| 下次开奖 | 未来 7 天开奖日程 |

### 首页集成
价值面板下方新增「🔔 今日提醒」区块，打开软件即见。
