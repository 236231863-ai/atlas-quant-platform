# Atlas v4.7 用户手册（User Manual）

版本：v4.7.0 · 2026-08-05

## 一、我可以问 AI 助手什么？

```
「分析我今年买彩票情况」→ 我的投注画像（投入/中奖/净收益/ROI/频率）
「我的购彩习惯怎么样」→ 购彩健康分（四维评分）
「我是不是亏很多」→ 资产分析（年度报告）
```

## 二、我的投注画像（10 指标）

- 总投入 / 总中奖 / 净收益 / ROI
- 平均每期投入 / 中奖次数 / 中奖等级分布
- 最大亏损周期 / 连续未中奖 / 投注频率

## 三、购彩健康分

```
🩺 购彩健康分：72/100（良好）
  资金管理 28/40 · 投注纪律 22/30 · 复盘习惯 14/20 · 风险意识 8/10
· 优势：每期投入稳定且克制
· 风险：购买频率过高
```

**不是中奖评分**——衡量行为管理，不代表中奖能力。

## 四、策略复盘（过去行为）

```
🔍 策略复盘
· 总投注 100 注 · 唯一组合 60 · 固定号码 40 · 随机 60
· 重复比例 67% · 倍投次数 40
```

**只回顾过去，不告诉你下一期怎么买。**

## 五、每周彩票报告

每周自动生成：本周购买次数 / 中奖情况 / 投入 / 风险提醒——每周回来看看自己的行为。

## 六、年度彩票报告

```
2026年度：投入 ¥5200 · 中奖 ¥860 · 净收益 ¥-4340 · ROI -83.5% · 最大回撤 ¥5200
```

诚实展示长期收益。

## 七、重要声明

**彩票开奖结果具有随机性，任何号码组合理论中奖概率相同。** Atlas 帮你管理、分析、复盘自己的购彩行为，不预测中奖，不承诺收益。
