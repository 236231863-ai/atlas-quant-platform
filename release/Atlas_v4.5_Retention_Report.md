# Atlas v4.5 留存报告（Retention Report）

版本：v4.5.0 · 2026-08-04

## 用户为什么回来（v4.5 回答）

| 时刻 | 留存钩子 |
|------|---------|
| 开奖日（周一/三/六大乐透，周二/四/日双色球） | 后台自动同步 + **关闭软件仍提醒** → 用户不担心错过 |
| 开奖后 | 自动兑奖 → 打开即见结果（含信任标注） |
| 长期 | 数据可信（官方+校验+健康等级）+ 长期复盘 + 行为报告 |

## 留存的差异化（vs 微信）

| Atlas | 微信开奖提醒 |
|-------|-------------|
| ✅ 自动兑奖（输入一次永久兑） | ❌ 手动对号 |
| ✅ 多注批量管理 | ❌ 单注查询 |
| ✅ 预算/复盘/风险/资产 | ❌ 无 |
| ✅ 数据来源+校验可见 | ❌ 黑盒 |
| ⚠️ 需安装桌面软件 | ✅ 零安装 |

**留存结论**：Atlas 必须赢在「微信没有的」——自动兑奖 + 多注 + 资产管家。

## 用户行为埋点（v4.5 新增）

| 事件 | 意义 |
|------|------|
| ticket_saved | 数据飞轮起点 |
| draw_reminder_received | 提醒触达 |
| draw_opened | 提醒→打开（留存转化） |
| claim_completed | 兑奖闭环完成 |
| report_viewed | 复盘/报告价值 |

**User Behavior Report** 用真实数据回答「为什么打开」，替代猜测。
