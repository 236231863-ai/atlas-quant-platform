# Atlas Quant Platform v4.0.0 产品报告

> 主题：Personal Decision Intelligence Layer 个人决策智能层
> 日期：2026-08-03
> 定位：从「彩票量化分析工具」升级为「个人智能决策助手」

---

## 1. 核心闭环

```
用户行为 → 数据积累 → 风险分析 → 行为洞察 → 方案优化 → 持续学习
```

**不是彩票预测**，而是帮助用户了解自己的投注行为并管理风险。

## 2. 产品边界（红线）

✅ 提供：行为分析 / 资金管理 / 历史复盘 / 风险洞察 / 持续改进
❌ 禁止：「预测中奖号码」「提高中奖概率」「稳赚」

所有输出明确随机性声明。

## 3. 用户问题（产品要解决的 5 个真实问题）

| # | 用户问题 | 系统响应 | 入口 |
|---|---------|---------|------|
| 1 | 我过去买了多少钱？ | 投入统计（月/年投入）| 个人中心/行为分析 |
| 2 | 我的投注习惯有没有问题？ | 行为风险等级 + 建议 | 个人中心/行为分析 |
| 3 | 我的资金风险是多少？ | 预算占比/超额提醒 | 工作台/资金管理 |
| 4 | 我的号码组合是否重复？ | 重复率/集中风险 | 量化中心/组合分析 |
| 5 | 历史行为是否改善？ | 趋势对比/改进评估 | 个人中心/趋势 |

## 4. 关键场景实测

```
用户：「我最近买彩票情况怎么样？」
Atlas：📊 你的投注行为分析
  · 投注期数：12 期 / 共 24 注
  · 总投入：¥96 · 月均投入：¥32 · 年投入外推：¥384
  · 追号次数：11 次 · 行为风险等级：D
  · 建议：追号次数较多，建议评估追号是否必要

用户：「我一年花多少钱？」
Atlas：💰 预算健康报告
  · 月预算：¥500 | 本月已投入：¥450（90%）
  · 年预算：¥6,000 | 今年已投入：¥3,600（60%）
  · 预算健康度：85/100

用户：「帮我复盘一下」
Atlas：📋 个人投注复盘
  · 过去一年投入 ¥936 · 中奖 ¥128 · 净收益 -¥808
  · 最高投入周期：8 月 · 中奖率 13.7%
```

## 5. 行为风险等级

| 等级 | 判断 | 建议 |
|------|------|------|
| A | 月投入 ≤100 或频率低 | 保持理性 |
| B | 月投入 100-500，频率中等 | 控制预算 |
| C | 月投入 500-1000，追号频繁 | 减少追号 |
| D | 月投入 >1000 或大量追号 | 强烈建议止损 |
