# Atlas v4.2 留存报告

> User Growth & Data Flywheel Sprint · 2026-08-03

---

## 1. 留存闭环（v4.2 数据飞轮）

```
保存票据 → 档案可见 → 开奖提醒 → 自动复盘 → 健康指数 → 年度报告 → 再次保存
   ↑                                                                ↓
   └────────────── 数据资产驱动留存 ────────────── 会员解锁沉淀 ←──┘
```

## 2. 50 用户模拟基线（seed=42）

```
· 第一次打开：100%
· 第一次保存：72%   ← 最大流失点（28% 不保存）
· 第一次提醒：56%
· 第一次兑奖：44%   ← 提醒→兑奖转化 79%
· 复盘查看：18%     ← 兑奖→复盘转化 41%（最大未开发价值）
· D7 留存：24%
· D30 留存：22%     ← 留存用户为「数据沉淀型」
```

## 3. 关键洞察

1. **打开→保存 72%**：北极星第一驱动是保存转化（Phase 1 档案 + 首次引导降低门槛）。
2. **提醒→兑奖 79%**：主动提醒是有效的行动钩子（v4.1.1 方向验证正确）。
3. **兑奖→复盘 41%**：自动复盘（Phase 2）正是为拉升此环节。
4. **D30 ≈ D7**：留下的用户一旦形成档案/预算习惯，留存坚韧。
5. **五辅助指标均无埋点**：模型是基线，需真实数据校准。

## 4. 本 Sprint 留存机制加固

| 机制 | 对应功能 | 留存作用 |
|------|---------|---------|
| 拥有感 | 个人档案 | 保存=资产累积，回访理由 |
| 自动服务 | 自动复盘 | 不打开也知道结果 |
| 健康目标 | 健康指数 | 改善行为→升级等级的长期目标 |
| 数据主权 | PDF 年度报告 | 我的数据可带走 |
| 变现钩子 | Premium | 沉淀型用户付费解锁 |

## 5. 结论

数据飞轮机制完整成型：**保存 → 价值 → 再保存**。D30 留存（22%）接近 D7（24%）证明飞轮一旦启动就坚韧；下一步是真实埋点验证北极星。
