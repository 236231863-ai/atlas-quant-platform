## 1. 产品冻结范围（v3.6.0）

### 冻结原则
- ✅ 使用现有 6 功能页面，**不新增研究模块**
- ✅ 不新增分析算法 / 策略 / AI 功能（AI 升级在 Phase 5 单独规划）
- ✅ 优先解决「用户下载安装」问题
- ✅ 保持向后兼容（E1/E2 成果不动）

### 冻结功能清单

| 模块 | 状态 | 说明 |
|------|------|------|
| Dashboard 数据看板 | ✅ 冻结 | 指标卡 + 最近开奖 + 冷热号 |
| Data Analysis 数据分析 | ✅ 冻结 | 频率/和值/跨度/奇偶图表 |
| Strategy Lab 策略实验室 | ✅ 冻结 | 3 策略 + 一键回测 |
| Backtest Center 回测中心 | ✅ 冻结 | ROI 曲线 + 明细表 |
| AI Assistant 智能助手 | ✅ 冻结 | 本地统计问答（Phase 5 升级） |
| Reports 研究报告 | ✅ 冻结 | 一键生成报告 |
| CLI / Worker | ✅ 冻结 | 命令行与后台服务 |
| 数据层 | ✅ 冻结 | 内置 CSV（Phase 3 接入真实数据） |

### 明确不包含（冻结排除）
- 不新增研究引擎模块
- 不新增彩种插件
- 不修改数据库 Schema
- 不修改核心算法
