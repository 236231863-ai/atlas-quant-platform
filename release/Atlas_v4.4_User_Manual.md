# Atlas v4.4 用户手册（User Manual）

版本：v4.4.0 · 2026-08-04

## 一、开奖数据如何自动更新？

**无需任何操作。** Atlas 通过两种方式保持开奖数据最新：
1. **启动时**：打开 Atlas 自动静默拉取官方最新开奖
2. **后台服务**：软件关闭时，Windows 计划任务每 30 分钟自动同步一次（可开机启动）

## 二、首页「开奖状态卡片」怎么看

打开首页即可看到：

```
📡 开奖状态
⏳ 距离下一开奖：大乐透 2026-08-05 · 双色球 2026-08-04
🩺 数据可信 A 级 · 最新 26087（2026-08-03）· 3 小时前
🎯 待兑奖 0 张
```

**数据可信等级**：
- **A**：正常同步（<12 小时）
- **B**：超过 12 小时未更新
- **C**：超过 24 小时未更新（建议联网）
- **D**：数据异常（无法读取/无数据）

## 三、自动兑奖

保存彩票后，开奖同步成功 → **自动**执行兑奖（无需手动问）：
1. 获取开奖结果
2. 自动匹配你的票据
3. 更新中奖状态
4. 通知你 + 生成兑奖报告

## 四、后台服务管理（可选）

后台服务默认随软件启动。高级用户可手动管理：
```
python tools/atlas_worker.py --once    # 立即同步一次
python tools/atlas_worker.py --loop    # 后台长驻循环
# 计划任务（Windows）：
schtasks /Query /TN Atlas\AtlasLiveDrawSync   # 查询状态
schtasks /Delete /TN Atlas\AtlasLiveDrawSync /F  # 移除
```

## 五、常见问题

- **Q：软件关闭会错过开奖吗？** 不会——后台计划任务持续同步；打开后立即看到最新。
- **Q：双色球数据为什么只到 2026-07-30？** 官方接口 gameNo=235 当前返回 0 条，双色球保持内置有效数据，大乐透实时正常。
- **Q：数据可信度 C/D 级怎么办？** 检查网络连接后重启 Atlas；数据为 D 时统计结论可能不稳健。
