## 1. 解决的问题

**原 bug**：用户在 AI 助手输入「7月31日买了这些号码…我中了多少钱」，系统回复「请提供开奖结果」——因为 AI 助手直接调 LLM，没经过业务 Intent Router。

**修复后**：AI 助手成为**任务执行助手**——识别业务意图 → 调用本地业务工具 → 完成闭环。

## 2. 架构

```
用户输入 → AssistantIntentRouter（识别任务）
  ├─ 业务任务 → Tool Registry 执行（prize/hot_cold/recommend/backtest/report）
  ├─ 缺信息   → 缺失信息引导（如"请提供号码"）
  └─ 闲聊     → 常规问答 / LLM
```

## 3. 工具注册表（复用已有能力，零新增算法）

| 工具 | 功能 | 复用模块 |
|------|------|----------|
| prize | 兑奖计算 | lottery_intent |
| hot_cold | 热号/冷号 | stats |
| recommend | 号码推荐 | stats.recommendation |
| backtest | 回测指引 | 回测中心 |
| report | 报告指引 | 研究报告 |

## 4. 验收场景（实测通过）

输入 15 注号码 +「8月1日开奖，我中了多少钱」→
1. ✅ 识别大乐透
2. ✅ 解析 15 注
3. ✅ 查询开奖（26086 期）
4. ✅ 调用 PrizeCalculator
5. ✅ 生成奖金报告（¥5,003,005，含一等奖）
