# Atlas v4.3.1 修复报告：开奖数据实时更新

版本：v4.3.1（Hotfix）· 2026-08-03

## 问题

用户反馈「开奖信息没有实时更新」。实证确认根因：
- 数据是打包时的**静态 CSV**（`data/raw/dlt_history.csv`，停在 26086 期 2026-08-01）
- 桌面启动只读本地文件，**不联网**
- 官方 API 能力存在（`APIDatasource`）但仅开发时手动使用，产品未接入
- 无定时/增量更新机制

## 修复

### 新增 `engine/data_center_v2/updater.py`
`IncrementalUpdater`：
- **增量拉取**：调用官方体彩 API 拉取最新开奖
- **合并去重**：按期号合并，远程覆盖（奖池可能更新），保留全部历史
- **内置 base**：首次更新以内置 1200 期为 base（不丢历史）
- **用户缓存**：写回 `~/.atlas/raw/{lottery}_history.csv`
- **24h 限频**：meta 文件记录上次更新时间
- **静默降级**：无网/API 异常不影响启动

### 修改 `desktop/data_loader.py`
- 用户缓存目录 `~/.atlas/raw` **优先于**项目/内置
- 来源标注「实时更新数据（官方 API，启动自动拉取）」
- 新增 `maybe_update_draws()` 入口

### 修改 `desktop/windows/main_window.py`
- 启动时**后台线程**静默更新 dlt + ssq（不阻塞 UI）
