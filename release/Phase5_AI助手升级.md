> Atlas Quant Platform v3.6.0 Product Launch
> 日期：2026-08-02

## 完成报告

### 双模式架构

```
AI 智能助手
  ├── 在线模式：配置 DeepSeek API Key → 真实大模型对话
  └── 离线模式：本地开奖统计规则问答（默认，零配置）
```

### 交付内容

| 项目 | 路径 | 说明 |
|------|------|------|
| 在线对话 | `desktop/pages/ai_page.py` | DeepSeek API 调用（urllib，无额外依赖） |
| API 配置 | AI 页「⚙ 配置 API」按钮 | 输入 Key 本地保存（~/.atlas/profile.json） |
| 模式指示 | AI 页状态标签 | 🟢 在线 / ⚪ 离线 清晰可见 |
| 双模式分流 | `_send()` | 在线有 Key → 大模型；否则本地统计 |
| 错误处理 | `_answer_online()` | 网络/Key 错误友好提示，不崩溃 |

### 用户操作

1. 打开 AI 智能助手 → 点击「⚙ 配置 API」
2. 输入 DeepSeek API Key → 确定
3. 模式切换为 🟢 在线，AI 使用真实大模型回答
4. 清除 Key → 回退离线模式

## 使用说明（用户角度）

### 1. 用户在哪里下载？
桌面 AI 助手内置，无需单独下载。

### 2. 用户如何安装？
无需安装。可选：配置 API Key 启用在线模式。

### 3. 用户如何第一次使用？
默认离线即可问「推荐号码/热号/奇偶」；升级体验：配置 API Key。

### 4. 用户获得什么价值？
- 离线：即时可用、免费、隐私安全
- 在线：接入真实大模型，回答更智能
- 灵活切换，按需升级
