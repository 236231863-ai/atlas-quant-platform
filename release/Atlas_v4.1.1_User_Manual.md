# Atlas v4.1.1 用户手册

> Retention Optimization Sprint · 2026-08-03

---

## 1. 首次使用（30 秒）
打开 Atlas → 首页引导「保存第一张彩票」→ 输入号码 → 开奖后 Atlas 自动提醒你
（无需任何配置，不用 API Key）

## 2. 首页「我的彩票」
| 指标 | 含义 |
|------|------|
| 🎫 我的票 | 已保存票据数 |
| ⏰ 最近开奖 | 今晚哪些彩种开奖 |
| 💰 待兑奖 | 已开奖待确认的票据 |
| 📊 本月投入 | 本月购彩花费 |
| 📈 本月结果 | 本月累计中奖 |
| 🎯 我的状态 | 理性购彩/需关注 |

动态话术：待兑奖提醒、本月 vs 上月投入对比、30 天中奖次数。

## 3. 开奖提醒
- 启动时自动检查今日开奖
- 桌面通知：「今晚大乐透开奖，你有 3 张彩票等待兑奖」
- 点击通知 → 跳转兑奖

## 4. 预算管家
- 周/月/年预算
- 提醒：「本周投入已达预算 80%」「已连续购买 4 周」
- 禁止赌博诱导，只做理性管理

## 5. 重要声明
> 彩票开奖结果具有随机性。Atlas 只提供提醒、记录、预算管理，不预测、不承诺提高中奖率。
