# Atlas Quant Platform v4.0.0 用户手册

> 个人决策智能层 使用指南
> 日期：2026-08-03

---

## 1. 快速开始

### 入口
- 导航「个人中心」页（我的票据/投入/中奖/风险/报告/趋势）
- AI 助手输入「我最近买彩票情况怎么样」「我一年花多少钱」「帮我复盘一下」

### 30 秒核心流程
1. 工作台添加票据（或 AI 助手输入号码保存）
2. 个人中心查看投入/中奖/风险
3. AI 助手「帮我复盘一下」查看复盘报告
4. 设置预算（工作台）控制支出

## 2. 功能说明

### 👤 个人中心
| 区块 | 内容 |
|------|------|
| 我的票据 | 已保存票据数 |
| 我的投入 | 总投入金额 |
| 我的中奖 | 累计中奖金额 |
| 我的风险 | 行为风险等级 A-D |
| 我的报告 | 复盘摘要 + 预算健康度 |
| 我的趋势 | 月度投入/年外推/追号/高频月份 |

### 📊 行为分析（AI：「我最近买彩票情况怎么样？」）
- 投注期数/注数/总投入
- 月均投入/年投入外推
- 追号次数/高频月份/停止率
- 行为风险等级 A-D + 建议

### 💰 预算管理（AI：「我一年花多少钱？」）
- 设置月/年预算
- 实际投入/预算占比
- 超额提醒/预算健康度

### 📋 历史复盘（AI：「帮我复盘一下」）
- 总投入/总中奖/净收益
- 投入收益比/中奖率
- 最高投入周期

### 📈 智能报告（量化中心）
5 部分：号码分析 / 概率分析 / 资金风险 / 个人行为 / 改进建议
- 「组合结构调整建议」替代「推荐号码」
- 支持 MD/PDF/PNG 导出

## 3. 行为风险等级

| 等级 | 含义 | 建议 |
|------|------|------|
| A | 低风险 | 保持理性 |
| B | 中低风险 | 控制预算 |
| C | 中高风险 | 减少追号 |
| D | 高风险 | 强烈建议止损 |

## 4. 重要声明

> ⚠️ 彩票开奖结果具有随机性，任何号码组合理论中奖概率相同。
> Atlas 只提供行为分析、资金管理、历史复盘与风险管理。
> 系统不会承诺「提高中奖概率」「稳赚」，也不提供彩票预测。

## 5. 常见问题

**Q：行为风险等级 D 是什么意思？**
A：月投入超过 ¥1000 或大量追号，属于高风险行为，建议设置预算并大幅减少投入。

**Q：预算超额会怎样？**
A：系统会提醒超额金额并给出「暂停购彩」建议，帮助你控制支出。

**Q：复盘为什么显示净收益为负？**
A：彩票为负期望游戏，长期投入大于回报是正常现象。复盘帮助你认清实际投入与回报。
