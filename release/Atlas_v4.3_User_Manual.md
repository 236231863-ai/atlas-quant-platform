# Atlas v4.3 用户手册（User Manual）

版本：v4.3.0 · 2026-08-03

## 一、快速开始（3 步，30 秒）

1. **打开 Atlas** → 首页「🎯 我的彩票」价值面板
2. **在 AI 助手输入你的号码**（例：`13 21 23 26 33 + 01 12`），或到「工作台」保存第一注
3. **等待开奖** → 开奖当天桌面自动弹提醒 → 自动兑奖

## 二、首页怎么看（3 秒价值）

| 看到什么 | 含义 |
|---------|------|
| 🎫 我的票 N 张 | 已保存的彩票数 |
| ⏰ 最近开奖 | 今晚哪个彩种开奖（大乐透一/三/六，双色球二/四/日） |
| 💰 待兑奖 N 张 | 已开奖等待查看的票据 |
| 📊 本月投入 ¥X | 本月购彩花费 |
| 📈 本月结果 | 本月累计中奖 |
| 🎯 我的状态 | 理性购彩 / 需关注 |

> 研究指标（平均和值/奇偶/冷热号）在「数据分析」页查看，首页只显示你的个人价值。

## 三、自动兑奖

- 保存票据后，开奖日 Atlas 自动匹配并生成兑奖报告（桌面通知）。
- 「我的待兑奖」列表 4 状态：
  - 等待开奖 → 已开奖待查看 → 已查看 → 已兑奖
- 兑奖报告含：购买日期 / 开奖日期 / 期号 / 投注注数 / 中奖注数 / 每注明细 / 总奖金。

## 四、个人中心

- **我的彩票档案**：累计购买 / 累计中奖 / 中奖次数 / 最高奖金 / 常购彩种
- **彩票资产中心**（红框）：中奖率 / 净收益 / 亏损率 / **风险等级 A-D** + 风险提示
- **我的成长**：保存/兑奖/报告次数 + 连续使用周数 + 成长等级
- **Atlas Premium**：会员解锁历史报告/年度分析/家庭预算（不含预测）

## 五、常见问题

- **Q：需要配置 API Key 吗？** 不需要。核心功能（保存/提醒/兑奖/预算）全部本地工作。
- **Q：软件不开会收到提醒吗？** v4.3 提醒在启动时弹出；后台定时通知是下一版本优化方向。
- **Q：Atlas 能预测中奖吗？** 不能。任何号码中奖概率相同，Atlas 只做管理、统计与风险提示。

## 六、免责声明

彩票开奖结果具有随机性。Atlas 提供票据管理、开奖提醒、统计分析与风险管理，不预测中奖，不承诺收益。
