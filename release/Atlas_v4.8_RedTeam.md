## 红队结论：第一次打开为什么留下

**冷启动场景（新用户无数据）能否留下 = v4.8 成败。** 关键链条：

```
30 秒理解价值（引导「建立档案」）
  → 选择导入方式（文本/CSV/OCR/手动）
  → 5 分钟建立档案
  → 立即生成画像/健康分/质量等级
  → 留存钩子：开奖提醒 + 每周报告
```

## 十大待修复

1. OCR 真实图片识别（当前为文本解析 + 外部引擎接口）
2. 双色球数据源
3. 隐私明示（本地存储）
4. 导入后立即展示档案价值
5. 老用户大量历史导入性能
6. 无票据引导建档 CTA 强化
7. 想预测用户转化教育
8. OCR 确认 UI
9. CSV 模板下载
10. 数据质量修复引导（重复票去重）

## 结论

**先优化 v4.8，不急于 v4.9。** 核心：冷启动建档闭环（导入→档案→价值）+ OCR 真实识别。
