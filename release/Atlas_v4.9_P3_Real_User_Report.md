## 二、REAL/SIM 隔离机制（已实现）

P3 已建立严格的数据来源隔离：

```python
SOURCE_REAL       = "REAL"        # 真实用户（含旧版 desktop 埋点）
SOURCE_SIMULATION = "SIMULATION"  # 模拟器数据
```

- `ExperimentTracker.normalize_source()` 统一标记
- `simulator.run()` 产出一律标记 SIMULATION
- `import_real_events()` 从真实埋点导入并标记 REAL
- 漏斗/留存/指标**默认只统计 REAL**（`source=None` 才混用，测试专用）
- **禁止混合统计**（`test_funnel_default_real_only` 等验证）
