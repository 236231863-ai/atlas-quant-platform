# Atlas v4.6 用户留存报告（Retention Report）

版本：v4.6.0 · 2026-08-04

## 运营四问（v4.6 数据基础）

| 问题 | 数据/机制 |
|------|----------|
| 用户为什么打开？ | app_opened 来源 + 首页兑奖汇总 + 开奖提醒 |
| 用户为什么保存？ | ticket_saved 转化（漏斗揭示瓶颈） |
| 用户为什么回来？ | Retention D1/D3/D7 + 月度复盘 + 资产积累 |
| 用户为什么付费？ | premium_view/click 意愿 |

## Retention Dashboard（新）

- **D1/D3/D7 留存率**：基于 app_opened 首次出现日 cohort
- **活跃天数分布**：每日活跃用户数
- **漏斗**：打开→保存→查看→兑奖→报告（各阶段转化/流失）

## 留存机制（v4.6 强化）

| 机制 | 说明 |
|------|------|
| 开奖前 24h/3h 提醒 | 提前召回（Task Scheduler 后台） |
| 开奖后兑奖提醒 | 结果主动送达 |
| 首页兑奖汇总 | 打开即见状态 |
| 月度复盘 | 每月回顾（资产积累） |
| 行为报告 | 数据驱动的留存优化依据 |
