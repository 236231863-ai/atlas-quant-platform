# Atlas v4.6 用户手册（User Manual）

版本：v4.6.0 · 2026-08-04

## 一、第一次打开（30 秒）

1. 欢迎页：「**以后不用记彩票开奖时间**」
2. 选择你常买的彩种
3. 点击「✓ 完成，我的彩票已保护」

## 二、首页今天看什么

```
🎯 今日兑奖
🎫 待开奖：2 张
🎉 已中奖：1 张
💰 待领取：¥7
```

3 秒知道你的彩票状态；点击可查看兑奖报告。

## 三、关闭软件还提醒吗？

**提醒。** Windows 后台任务在开奖前自动提醒：
- 📅 **开奖前 1 天**：`大乐透明日开奖`
- ⏰ **开奖前 3 小时**：`大乐透即将开奖`
- 🎯 **开奖后**：自动兑奖提醒

> 每类提醒当天只发一次，不打扰。

## 四、月度复盘（诚实）

```
📅 月度复盘报告
· 2026年8月：购买 ¥120 · 中奖 ¥7 · 净收益 ¥-113
· 累计净收益：¥-113
· 复盘仅陈述历史事实。彩票长期为负期望，理性购彩。
```

## 五、Premium（付费意愿验证）

免费用户可见「升级 Atlas Premium 解锁」：自动兑奖提醒 / 年度彩票报告 / 无限历史保存 / 家庭彩票管理。

> 本版本只验证付费意愿（记录查看/点击），**不实际扣费**。

## 六、我的行为数据

Atlas 记录匿名行为（打开/保存/查看/兑奖/报告），用于回答「用户为什么打开」，不包含个人信息。

## 七、免责声明

彩票开奖结果具有随机性。Atlas 提供管理、提醒、复盘，不预测中奖，不承诺收益。
