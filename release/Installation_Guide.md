# Atlas Quant Platform v3.6.1 安装指南

本指南适用于 Windows 10 / 11（64 位）。提供两种安装方式：**安装包**（推荐）与**便携版**。

---

## 方式一：安装包（推荐）

1. **下载**：获取 `AtlasQuant-3.6.1-Setup.exe`（约 156 MB）。
2. **运行**：双击安装包。
   - 若出现 SmartScreen「Windows 已保护你的电脑」提示，点击「更多信息」→「仍要运行」。
   - 安装向导将引导你完成安装（默认路径 `C:\Program Files\Atlas Quant Platform`）。
3. **完成**：安装后自动创建桌面快捷方式与开始菜单项。
4. **启动**：双击桌面快捷方式「Atlas Quant Platform」即可。

**卸载**：进入「设置 → 应用」或在开始菜单找到「卸载 Atlas Quant Platform」。

---

## 方式二：便携版（免安装）

1. **下载**：获取 `AtlasQuant-3.6.1.zip`（约 154 MB）。
2. **解压**：右键 → 全部解压缩，得到 `Atlas.exe` 等文件。
3. **运行**：双击 `Atlas.exe` 即可使用，无需安装。

> 便携版适合 U 盘携带；不会写入系统注册表。

---

|------|------|
| 操作系统 | Windows 10 / 11 64 位 |
| 内存 | ≥ 4 GB（建议 8 GB） |
| 磁盘 | ≥ 500 MB 可用空间 |

## 首次使用（三步，30 秒）

1. **选择用途**：快速看数据 / 回测验证策略 / 生成报告。
2. **选择彩种**：大乐透 / 双色球。
3. **选择分析模式**：快速分析 / 深度回测。

完成后软件自动进入对应页面，内置 **520 期真实大乐透历史数据**，开箱即用。

## 常见问题

**Q1：提示"数据不足"？**
A：内置 520 期大乐透数据（可信等级 A）。若你导入了更小数据集，会看到黄色警告；导入 ≥500 期后恢复为可信。

**Q2：回测结果能保存吗？**
A：可以。回测页支持「明细 CSV / 报告 PDF / 图表 PNG」导出；报告页支持「MD / PDF / CSV」。

**Q3：AI 助手怎么用？**
A：默认离线模式（本地统计问答）。想要真 AI 对话，点击「⚙ 配置 API」填入 DeepSeek API Key 并保存，即切换在线模式。

**Q4：如何导入自己的数据？**
A：将开奖 CSV 放入 `data/raw/`（或用户目录 `~/.atlas/data/`），命名 `dlt_history.csv` / `ssq_history.csv`，格式：`issue,date,numbers,pool`（numbers 如 `10 11 18 22 35|06 12`）。

**Q5：运行报错/崩溃？**
A：软件已内置崩溃日志（`~/.atlas/logs/`）。下次启动会提示恢复；若持续异常，可导出日志反馈。
