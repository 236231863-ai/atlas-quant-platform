## 2. 用户价值分析

核心价值：中奖早知道 · 花钱有数 · 每期有复盘
本 Sprint 强化：
- **真开奖提醒**（桌面通知 + 票据状态机）→ 中奖早知道
- **首页 6 价值指标** → 花钱有数
- **预算提醒**（80%/连续购买）→ 花钱有数
- **首次引导**（30 秒价值）→ 新人上手

## 3. 留存模型

```
开奖提醒（主动）→ 用户回来 → 待兑奖点击 → 兑奖 → 预算更新 → 连续记录 → 长期
```

留存钩子：开奖通知（每周 6 次）、待兑奖状态机、预算预警、连续购买周数。

## 4. 商业化可能

- 自动兑奖提醒（¥6-12/月）
- 预算管家（¥3-6/月）
- 年度报告（¥9.9）
付费前提：留存验证（周留存 ≥30%）。

## 5. 下一阶段建议

补核心埋点（保存/兑奖/提醒点击）→ 采集 7 天留存 → 验证漏斗。
