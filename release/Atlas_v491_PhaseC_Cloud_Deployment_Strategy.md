# Atlas v4.9.1 — Phase C 云端化部署策略（Cloud Deployment Strategy）

> 阶段：Phase C · 性质：**方案设计（P0 冻结功能，不开发）**
> 目标：解除局域网限制，让真实用户**异地**使用小程序
> 前置：微信登录已接入（code2session → openid → U_ID）

---

## P0 产品冻结

- ❌ 不新增任何业务功能
- ❌ 不修改彩票逻辑 / 页面结构 / 埋点体系
- ✅ 只做：云端架构选型 + 迁移方案 + 登录 + 数据安全

---

## P1 云端架构设计（A 腾讯云服务器 vs B 微信云开发）

### 方案对比

| 维度 | A. 腾讯云服务器 | B. 微信云开发 |
|------|---------------|-------------|
| **开发复用** | ✅ 直接部署现有 FastAPI（零改写） | ❌ 需改写为云函数/云托管（Node 或容器） |
| **月成本** | 约 ¥50-100（轻量 2C2G）+ 域名 ~¥5/月 + SSL 免费 | 按量付费；免费额度内 ~¥0，超出后低费用 |
| **成本可预测性** | ✅ 固定月费 | ⚠️ 随用户量线性，不可预测 |
| **数据控制** | ✅ 自管 SQLite/Postgres，可导出可迁移 | ⚠️ 数据在微信云，迁移成本高 |
| **运维负担** | ⚠️ 需自己管系统更新/安全/备份 | ✅ 免运维 |
| **HTTPS/域名** | 需自配域名 + 证书 | ✅ 自带域名 |
| **微信生态集成** | ⚠️ 需在小程序后台配 request 合法域名 | ✅ 天然集成 |
| **未来扩展** | ✅ 桌面端+云端账户+多端同步需自有后端 | ⚠️ 锁定小程序场景，桌面端难接入 |
| **平台锁定** | ✅ 无锁定，可迁阿里云/AWS | ⚠️ 强锁定微信生态 |

### 结论：**推荐 A（腾讯云服务器）**

**核心理由**：
1. **代码零改写**：现有 FastAPI + SQLite 可直接部署，微信云开发需重构
2. **未来形态需要**：Atlas 愿景是「桌面 + 小程序 + 云账户」组合（v4.9 验证结论），自有后端是唯一可行路径
3. **数据主权**：彩票数据敏感，自管数据库可导出/备份/合规
4. **成本可控**：Beta 阶段轻量服务器固定 ¥50-100/月，远低于开发重构成本

> ⚠️ B（微信云开发）适合纯小程序 + 快速验证，但 Atlas 有桌面端和多端未来，A 更符合长期。

## P2 后端迁移方案（FastAPI + SQLite → HTTPS API + 云数据库）

### 目标架构

```
手机小程序 ──HTTPS──> 腾讯云服务器
                        ├─ Nginx（HTTPS 终止 + 反向代理）
                        ├─ FastAPI（backend/mobile，现有代码）
                        ├─ SQLite（初期）→ Postgres（中期）
                        └─ 定时备份
```

### 迁移路径（分 3 步）

| 步骤 | 内容 | 说明 |
|------|------|------|
| **1. 上云（1-2 天）** | 轻量服务器部署 FastAPI + Nginx + HTTPS | 代码零改，SQLite 文件随服务器 |
| **2. 数据库稳定化（1 天）** | SQLite 定时备份 + 迁移脚本 | 防数据丢失 |
| **3. 升级 Postgres（可选，用户量>100 后）** | 迁移到云数据库 | 并发/可靠 |

### HTTPS 配置要点
- 域名：`api.atlas-lottery.com`（示例，需购买）
- SSL：腾讯云免费 DV 证书（1 年）
- 小程序后台：配置 **request 合法域名** = `https://api.atlas-lottery.com`

### 部署清单（产品负责人操作）
```
1. 购买腾讯云轻量服务器（2C2G，~¥50/月）+ 域名
2. 安装 Python 3.11+/uvicorn/nginx
3. 上传 backend/mobile + 依赖
4. 配置 WECHAT_APPID / WECHAT_APPSECRET 环境变量
5. 启动 uvicorn + nginx HTTPS
6. 小程序后台配置 request 合法域名
7. 更新 mobile_app/utils/api.js 的 BASE → https 域名
8. 重新上传体验版
```

## P3 微信真实登录方案

**已实现（Beta 前置完成）**，云端部署时只需：

| 项 | 配置 |
|----|------|
| 后端环境变量 | `WECHAT_APPID` / `WECHAT_APPSECRET` / `WECHAT_LOGIN_MOCK=0` |
| 小程序 | `wx.login` → `code` → `POST https://域名/api/auth/wechat/login` |
| 绑定 | openid ↔ U_ID（唯一约束，同微信用户稳定身份） |
| 域名校验 | 小程序后台把 `https://api.atlas-lottery.com` 加入 request 合法域名 |

> ⚠️ 注意：小程序正式/体验版要求 **HTTPS** 且域名在后台白名单。局域网 IP 不可用于真实分发。

## P4 数据安全方案

### 用户隔离
- ✅ openid 唯一约束（数据库层）
- ✅ U_ID 永久稳定，用户数据按 U_ID 隔离查询
- ✅ 接口层 user_id 校验（核对 ticket 归属）

### 备份策略
| 频率 | 内容 | 方式 |
|------|------|------|
| 每日 | `mobile_mvp.db` | 定时任务 + 对象存储/本机副本 |
| 每周 | 全量 + 开奖数据 | 压缩归档 |
| 部署前 | 手动快照 | 迁移时 |

### 日志安全
- ✅ 不记录 openid/session_key/AppSecret 到日志
- ✅ 用户事件只存行为（不存隐私）
- ✅ 访问日志脱敏（IP 可保留，无身份关联）

### 合规
- 彩票数据敏感，云服务器需：
  - 限制 SSH 白名单（仅管理员 IP）
  - 数据库不暴露公网（仅本机/内网）
  - 定期更新系统补丁

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 服务器被攻击 | SSH 白名单 + 数据库不公网 + 系统更新 |
| 数据丢失 | 每日备份 + 恢复演练 |
| 域名/证书过期 | 年付 + 提醒 |
| 用户量激增 | Postgres 迁移 + 扩容预案 |
| 微信封禁域名 | 合规内容 + 备案（境内服务器需 ICP 备案） |

> ⚠️ **ICP 备案**：腾讯云大陆服务器需域名备案（约 7-20 天），Beta 前需提前办理。或选香港节点（免备案，延迟略高）。

---

## 结论

> **推荐：腾讯云轻量服务器（A）**——代码零改写、数据自主、符合 Atlas 多端未来。Beta 阶段月成本约 ¥60-80。关键前置：**域名 + ICP 备案 + HTTPS 配置**（产品负责人操作，约 1-2 周）。
