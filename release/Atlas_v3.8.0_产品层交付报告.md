## 4. 核心能力

- **票据管理**：从自然语言自动解析保存票据。
- **报告中心**：每次兑奖自动保存，累计奖金可见。
- **追号观察**：遗漏统计（严格非预测）。
- **个人工作台**：一个页面看票据/报告/追号/偏好。
- **用户记忆**：偏好持久化 + 对话上下文。
- **连续对话**：报号码→问中奖，无需重复。
