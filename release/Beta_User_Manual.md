# Atlas Beta 用户手册（v3.7.1-beta）

> 欢迎参与 Atlas Beta 测试！本手册带你完成从安装到反馈的完整体验。

---

## 1. 安装

- **安装包**：`AtlasQuant-3.7.1-beta-Setup.exe`（双击安装）。
- **便携版**：解压 `AtlasQuant-3.7.1-beta.zip`，运行 `Atlas.exe`。

## 2. 首次使用（5 分钟上手）

1. **三步引导**：用途 → 彩种 → 分析模式。
2. **第一份报告**：自动生成并展示（无需手动操作）。
3. **数据看板**：1200 期大乐透 + 500 期双色球，可信等级 A。
4. **回测**：样本外 ROI + 随机基准对照，诚实评估。

## 3. 功能速览

| 页面 | 说明 |
|------|------|
| 📊 数据看板 | 数据概况 + 每日摘要 |
| 📈 数据分析 | 频率/和值/跨度/奇偶图表 |
| 🧪 策略实验室 | 三种策略 + 一键回测 |
| 📉 回测中心 | 诚实回测 + 明细导出 |
| 🤖 AI 助手 | 离线问答 / 在线大模型 |
| 📄 研究报告 | 一键生成 + MD/PDF/CSV 导出 |

## 4. 帮助中心

点击窗口顶部菜单栏「🆘 帮助」，可查看：
- 常见问题（FAQ）
- 更新说明
- 安装指南
- **提交反馈**（输入问题/建议 → 提交）

## 5. 反馈指引

通过帮助中心提交反馈时，请尽量包含：
- 问题描述
- 复现步骤
- 截图（可选）

我们会按流程处理：New → Reviewing → Fixed → Closed。

## 6. 数据说明

- 大乐透：1200 期（2018-07 ~ 2026-08），体彩官方 API。
- 双色球：500 期（2023-04 ~ 2026-07），福彩官方 API（单次上限限制）。
- 本软件会记录**匿名使用数据**（页面/功能/导出），仅用于改进产品，数据存本机。
