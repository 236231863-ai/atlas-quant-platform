# Atlas v4.9.1 — 14 天实验计划（14-Day Experiment Plan）

> 状态：✅ 计划已冻结，等待 P2 采集
> 目标：50–100 名 A 类真实用户，14 天验证「真实购彩者是否愿意每周打开 Atlas」

---

## 一、实验周期

**T+0 至 T+13（14 天）**，从产品负责人启动分发日算起。

---

## 二、用户招募（P2 执行）

| 渠道（允许） | 说明 |
|-------------|------|
| 朋友测试 | 优先，可控 |
| 彩票交流群 | 精准 A 类用户 |
| 小范围种子用户 | 50–100 人 |

| 渠道（禁止） | |
|-------------|--|
| 模拟用户 / 自动生成 / 压测数据 | ❌ |

招募后统一分配 U0001–U0050+。

---

## 三、每日实验记录（Daily Experiment Log）

产品负责人**每天**必须记录（模块已就绪）：

| 字段 | 说明 |
|------|------|
| `date` | 日期 |
| `new_users` | 新增用户 |
| `first_open` | 首次打开 |
| `ticket_saved` | 保存彩票 |
| `reminder_enabled` | 提醒开启 |
| `draw_checked` | 开奖查看 |
| `claim_completed` | 兑奖完成 |
| `asset_viewed` | 资产查看 |
| `weekly_report_viewed` | 周报查看 |
| `feedback_count` | 反馈数量 |

存储：`~/.atlas/daily_log_v491.jsonl` · 导出：`daily_log_v491_export.csv`

---

## 四、提醒价值统计（重点）

| 指标 | 公式 | 目标 |
|------|------|------|
| 提醒点击率 | `reminder_clicked / reminder_sent` | **≥30%** |
| 提醒→查看开奖率 | `draw_checked_after_reminder / reminder_sent` | 记录 |

存储：`~/.atlas/reminder_value_v491.jsonl`

## 六、关键节点

| 节点 | 检查 |
|------|------|
| T+1 | 首批 ≥10 用户注册，首次建档率初步 |
| T+3 | 累计 ≥30 用户，D1 留存初值 |
| T+7 | **D1/D7 关键判断**，提醒点击率 |
| T+13 | 数据封板，进入 P3 分析 |
| T+14 | P3/P4/P5 报告 + CEO 决策 |

---

## 七、实验护栏（fail-fast）

| 护栏 | 触发动作 |
|------|---------|
| 首次建档率 <50% | P2 Review 标记 B（调整方案） |
| 用户数 <50 | 延长采集或扩大招募 |
| 提醒点击率 <30% | 定位提醒触达问题 |
| 数据异常 | 检查埋点链路，修复后继续 |

---

## 八、禁止

- ❌ 实验期间新增功能 / 优化 UI / 云同步 / 手机端
- ❌ 模拟数据进入真实统计
- ❌ 伪实时双色球数据
