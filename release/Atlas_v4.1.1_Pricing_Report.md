## 定价锚点
- 对标「一注彩票 2 元」：¥9/月 ≈ 4.5 注/月 → 用户感知低
- 对标「彩票 App 会员」：¥6-12/月 常见

## 付费转化逻辑
```
免费版价值（兑奖+首页）→ 开奖提醒触达 → 预算预警触发付费动机 → 年度报告完成转化
```

## 红线
- 不卖预测/提高概率（违法红线，毁信任）
- 付费点 = 省时 + 省钱 + 仪式感
