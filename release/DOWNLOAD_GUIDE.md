# Atlas Quant Platform — 下载与安装指南

> 面向终端用户的下载页文案

---

## 在哪里下载？

### 方式一：GitHub Release（推荐）
访问项目 GitHub Releases 页面，下载 v3.6.0 版本：
- **Atlas_Setup.exe** — Windows 安装版（推荐）
- **Atlas_Portable.zip** — 免安装便携版

### 方式二：本地发布目录
若从内部渠道获取，安装包位于 `release/` 目录。

---

## 如何安装？

### 安装版（Atlas_Setup.exe）
1. 双击 `Atlas_Setup.exe`
2. 选择语言（简体中文 / English）
3. 跟随向导 → 选择安装路径
4. 可选创建桌面快捷方式
5. 完成后自动启动

### 便携版（Atlas_Portable.zip）
1. 解压到任意目录（如 `D:\Atlas Quant Platform`）
2. 双击 `Atlas.exe` 运行

---

## 第一次使用

1. 首次启动 → 欢迎向导（设置您的称呼）
2. 进入数据看板，查看开奖统计
3. 左侧导航切换 6 大功能模块
4. 可选：导入真实数据 / 配置 AI

## 系统要求

- Windows 10/11（x64）
- 内存 4GB+
- 磁盘 500MB+

## 遇到问题？

- 安装失败 → 检查磁盘空间 / 关闭杀毒软件
- 启动闪退 → 使用便携版测试 / 查看日志
- 数据为空 → 确认数据文件存在（内置演示数据默认可用）
