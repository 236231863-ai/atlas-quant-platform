# Atlas v4.1 用户研究报告

> 冲刺结束 · 2026-08-03

## 目标用户画像
大众购彩者：每周买 2-5 注，想知道中没中，花钱没数，偶尔追号。

## 用户行为洞察（真实数据）
- 973 次启动中 95% 是打开即走 → 缺留存钩子
- 页面访问均匀无高频 → 没有"非用不可"的功能
- 本次 v4.1 增加开奖提醒/预算预警 → 针对"打开即走"的根因

## 10 角色验证结论
| 角色 | 核心需求 | v4.1 满足 |
|------|---------|-----------|
| 新手 | 输入→结果 | ✅ 30 秒闭环 |
| 老用户 | 每日价值 | ✅ 今日提醒 |
| 倍投 | 追号预警 | ✅ 追号+亏损率 |
| 理性 | 预算控制 | ✅ 周/月/年 |
| 合买 | 多票管理 | ⚠️ 基本满足 |
| 分析 | 统计工具 | ✅ |
| 收藏 | 记录成就 | ✅ 连续记录 |
| 兑奖 | 最快查中 | ✅ 提醒直达 |
| 长期 | 年度报告 | ✅ |
| 小白 | 引导上手 | ✅ |

## 核心发现
1. **开奖节奏 = 天然召回**（每周 6 次），最大资产
2. **用户要的是结果不是数据**（中没中 > 冷热号）
3. **负期望是卖点**（预算/复盘帮用户省钱，而非鼓励多买）

## 用户旅程痛点
- 首次无引导「保存票据」→ 建议加首次保存引导
- 提醒是静态区块 → 应可点击直达兑奖
