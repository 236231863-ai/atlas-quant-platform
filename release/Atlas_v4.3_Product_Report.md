# Atlas v4.3 产品报告（Product Report）

版本：v4.3.0 · 主题：User Retention Loop · 2026-08-03

## 产品定位

**Atlas = 帮购彩者管理每一注彩票。**

一句话：**中奖早知道 · 花钱有数 · 每期有复盘**。
不是预测工具，不是统计平台，是留存闭环驱动的彩票管家。

## 本次 Sprint 解决的问题

| 问题 | v4.3 方案 | 验收（用户行为发生） |
|------|-----------|---------------------|
| 提醒不是真提醒 | 桌面通知 + 开奖倒计时 + 提醒事件 | 保存票据后开奖当天桌面弹出提醒（事件可查） |
| 兑奖要主动问 | 自动兑奖中心（4 状态机 + auto_claim） | 开奖→自动匹配→通知→报告（事件可查） |
| 花钱没数 | 彩票资产中心（含风险等级 A-D） | 资产报告 + 风险提示可见 |
| 没理由留下 | 用户成长系统（连续周数 + 年度 Atlas Report） | 真实事件驱动的成长数据 |
| 首屏无价值 | 首页重构第二版（3 秒价值） | 第一屏=我的票/开奖/待兑/本月投入 |

## 核心价值闭环

```
保存票据 → 开奖提醒（桌面） → 自动兑奖 → 待兑奖列表 → 资产/预算/成长 → 再保存
```

## 关键数据

- 测试：tests/v43 **846 场景**（要求 ≥800）
- 用户行为事件：ticket_saved / reminder_shown / claim_viewed / claim_confirmed / auto_claim_run / report_generated
- 首页：移除平均和值/奇偶/冷热研究指标（移至数据分析页）

## 红线

- 无号码推荐、无「提高中奖概率」、无诱导购彩
- 所有报告含「彩票开奖结果具有随机性」免责声明
- 资产/复盘诚实展示负期望与风险

## 结论

v4.3 从「加功能」转向「强化留存闭环」：**用户行为发生**（事件记录）是每个功能的验收标准，而非「页面存在」。
